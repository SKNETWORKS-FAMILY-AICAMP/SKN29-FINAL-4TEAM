1. 업무 대시보드
- 문의 종류별로 처리해야 하는 건 수 한 눈에 보이도록 "지금 할 일" 카드 목록 구현
- 각 카드를 누르면 처리해야 할 업무 리스트 확인 가능
- AI 요약 검수 필요한 리스트 별도로 확인 가능

2. 새 문의 / 처리 중인 문의 / 처리 완료된 문의
- 문의 제목 | 문의 관련 태그 (문의 핵심) | 고객명 으로 문의 리스트 구성
- 문의 리스트를 누르면 고객번호, 모델명, 문의 내용 전체 내용 등 상세 내용 전부 확인 가능
