# Web 실제 서버 연결 요청표

> 작성일: 2026-08-07
> 작성자: 한예나
> 목적: 상담사 Web의 예시 데이터를 실제 서버 데이터로 바꾸기 위해 필요한 내용을 확정한다.

## 1. 현재 상태

- 상담사 목록·상세·상담 결과·방문 일정 화면은 구현되어 있다.
- 화면 자동 테스트 117개와 코드 검사·배포용 빌드는 통과했다.
- 현재 업무 데이터는 예시 데이터이며 실제 DB 저장이 아니다.
- Web은 서버 주소와 데이터 형식을 임의로 만들지 않고 확정 내용을 기다린다.

## 2. PM 요청

| 요청 내용 | 완료 기준 |
| --- | --- |
| 상담사 목록·상세 범위 승인 | 화면에 필요한 조회 항목과 권한 범위 확정 |
| 상담 시작·저장·완료 행동 승인 | 각 행동을 실행할 수 있는 문의 상태와 역할 확정 |
| 방문 요청·일정 저장 범위 승인 | 방문 희망일·확정일·기사 배정 상태 구분 확정 |
| 행동 23개 연결표 승인 | 행동별 서버 기능·담당 코드·완료 여부가 한 표에 정리됨 |

## 3. 백엔드 요청

| 기능 | Web에 필요한 값 | 완료 기준 |
| --- | --- | --- |
| 상담사 문의 목록 | 검색, 상태, 위험도, 우선순위, 기간, 정렬, 페이지 조건 | 확정된 서버 주소와 실제 응답 예시 제공 |
| 목록 결과 | 문의 번호, 증상, 마스킹 고객명, 제품, 상태, 위험도, 우선순위, 대기 시간, 담당자 | 실제 DB 값을 조회할 수 있음 |
| 문의 상세 | 고객·제품·구독·문진·자가조치·AI 결과·공식 근거·상태 이력 | 한 문의의 상세 값을 실제 DB에서 조회할 수 있음 |
| 상담 시작·임시 저장·완료 | 상담 기록, 방문 필요 여부, 수정한 AI 요약, 상태 버전 | 저장 후 최신 상태와 가능한 다음 행동이 반환됨 |
| 방문 요청·일정 저장 | 방문 희망일, 방문 확정일, 일정 상태, 담당 기사, 기사 메모 | 저장 후 새로고침해도 같은 값이 조회됨 |
| 오류 결과 | 로그인 만료, 권한 없음, 자료 없음, 동시 수정, 입력 오류, 서버 오류 | 오류 종류와 사용자 안내에 필요한 값 제공 |

서버 주소, 요청 방식과 필드 이름은 백엔드가 확정해 공유한다. Web은 확정 전 주소나 필드를 임의로 추가하지 않는다.

## 4. 공통 필수값

- 현재 상태와 상태 버전
- 현재 화면에서 가능한 행동 목록
- 중복 저장 방지 값
- 요청 추적 값
- 마스킹된 고객 정보
- 성공 후 최신 문의·상담·방문 정보
- 오류 코드와 쉬운 안내 문구에 필요한 상세값

## 5. Web 연결 시작 조건

다음 항목이 모두 준비되면 실제 연결을 시작한다.

1. PM 승인
2. 확정된 서버 기능 문서
3. 실제 실행 가능한 백엔드
4. 성공·오류 응답 예시
5. 상담·방문 데이터가 저장되는 테스트 계정과 문의

## 6. 연결 완료 기준

- 예시 데이터 설정을 끄고 상담사 목록과 상세가 실제 서버 데이터로 표시됨
- 상담 결과와 방문 일정이 실제 DB에 저장됨
- 새로고침 후 저장한 값이 유지됨
- 권한·동시 수정·입력 오류가 화면에 올바르게 표시됨
- Web 자동 테스트·코드 검사·배포용 빌드가 다시 통과함
