## 05. 자체 평가 대체 자료

### Backend가 연결되지 않을 때

> 실제 Backend 계약이 아직 확정되지 않아 합성 Mock 결과로 Web 수행 경과를 보여 드리겠습니다. 실제 저장 완료를 의미하지 않습니다.

### Web이 실행되지 않을 때

> 실행 환경 문제로 준비된 캡처를 사용하겠습니다. 캡처는 마지막으로 정상 확인한 합성 Mock 화면입니다.

### 409 시연이 실패할 때

> 409 캡처에서 사용자가 작성한 내용이 유지되고 최신 상태만 반영되며 자동 재시도하지 않는 결과를 확인할 수 있습니다.

### 개선 방향

> 화면과 오류 처리는 준비됐지만 실제 상담·방문 저장은 Backend Active 계약 뒤 연결하는 것이 다음 개선 과제입니다.

## 금지 표현

- “실제 고객 데이터입니다.”
- “실제 Backend 저장까지 완료됐습니다.”
- “기사 배정이 실제로 등록됐습니다.”

대신 `합성 Mock`, `Mock 검증 완료`, `Backend 계약 대기`, `실제 저장 아님`으로 설명한다.
