## 발표 항목별 복사 문장

### 01 프로젝트 개요

> WaterBridge는 정수기 고객의 문의부터 AI 안내, 상담, 방문 A/S, 해결 확인까지 하나의 문의 이력으로 연결하는 AI 고객케어 플랫폼입니다.

### 02 팀 구성 및 역할

> 6명의 팀원이 PM·Web·Mobile·Backend·AI·Data/QA 역할을 나누었고, Web은 상담사와 운영 담당자 화면을 맡았습니다.

### 03 수행 절차 및 방법

> Web은 화면·계약 분석, Mock 구현, 실행 기준선 재검증, Runtime 정리, Backend 계약 검토, 발표 준비 순서로 진행했습니다.

### 04 수행 경과

> Web 자동 테스트 27개 파일·113개 케이스가 모두 통과했고 Lint 오류 0건, Production Build 118 modules 성공을 확인했습니다. 공식 대표 문의 DEMO-INQ-002와 매뉴얼 38쪽 근거, 409 입력 유지, 방문 전환을 구분해 시연합니다.

### 05 자체 평가

> 화면 흐름과 오류 처리, 자동 검증, 발표 자료는 준비했지만 실제 상담·방문 저장은 Backend 계약 미확정으로 남아 있습니다. 따라서 Web 자체평가 초안은 8점이며 실제 API 연결과 최종 리허설을 다음 개선 과제로 두었습니다.

> WaterBridge는 고객·상담사·방문기사·운영 담당자 4개 역할을 연결하는 프로젝트입니다. Web은 상담사·운영 화면을 담당했으며 Mock 기준 Test 27개 파일·113개 케이스 통과, Lint 오류 0건, Build 118 modules 성공을 확인했습니다. 공식 대표 문의 DEMO-INQ-002의 완료 상세·매뉴얼 38쪽 근거와 행동 전용 문의의 409 입력 유지·방문 전환을 시연합니다. 실제 상담·방문 저장 0건은 Backend Active 계약 대기 상태이므로 완료 수치에 포함하지 않습니다.
