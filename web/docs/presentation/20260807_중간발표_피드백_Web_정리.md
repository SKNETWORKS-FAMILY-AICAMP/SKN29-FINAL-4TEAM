# 중간발표 피드백 Web 반영 정리

> 작성일: 2026-08-07
> 작성자: 한예나
> 범위: 심사위원·강사 피드백 중 Web 화면과 시연 설명에 해당하는 내용

## 1. 반영 완료

| 피드백 | Web 반영 내용 |
| --- | --- |
| 누가 사용하는 화면인지 헷갈림 | 상담사 화면은 고객 문의를 처리하는 내부 업무 화면으로 구분 |
| 실제 기능과 예정 기능이 섞여 보임 | 상단에 실제 서버 연결 대기와 예시 데이터 사용 안내 표시 |
| 화면 분위기가 서로 다름 | 상담사 화면을 운영자 화면과 비슷한 밝은 하늘색·연보라색으로 수정 |
| 화면이 빠르게 지나가 이해하기 어려움 | 목록 → 상세 → 상담 입력 → 방문 선택 순서로 확인할 항목 정리 |
| 어려운 기술 용어가 많음 | 화면 문구는 고객 문의, 상담 기록, 방문 필요 등 업무 표현을 우선 사용 |

## 2. 발표·시연에서 구분할 내용

| 화면 | 사용자 | 현재 상태 | 설명 문구 |
| --- | --- | --- | --- |
| 고객 앱 | 고객 | 일부 실제 연결·일부 예시 | 고객이 증상을 접수하고 안내를 받는 화면 |
| 상담사 Web | 상담사 | 화면 완료·실제 저장 대기 | 접수된 문의를 확인하고 상담·방문을 판단하는 내부 화면 |
| 방문기사 앱 | 방문기사 | 예시 화면·실제 연결 대기 | 배정된 방문 건과 사전 점검 내용을 확인하는 화면 |
| 운영자 Web | 운영자 | 운영 현황 예시 화면 | 전체 문의와 처리 현황을 확인하는 내부 관리 화면 |

상담사 Web과 방문기사 앱의 예시 동작을 실제 서버 저장 완료로 설명하지 않는다.

## 3. 서버 연결 후 추가 반영

- 상담 처리 시간과 방문 인계 시간의 전후 비교 표시
- 상담 결과가 기사 화면에 전달되는 실제 흐름 표시
- 고객·상담사·기사·운영자별 얻는 이점 한 줄 설명
- 실제 저장 성공과 오류 상황을 화면에서 확인
- 고객 → 상담사 → 방문기사 → 고객 완료 흐름을 천천히 단계별로 시연

## 4. 발표 설명 예시

“고객은 모바일 앱에서 불편 사항을 접수합니다. 상담사는 Web에서 고객 답변과 공식 근거를 확인하고 상담으로 끝낼지 방문이 필요한지 결정합니다. 방문이 필요하면 기사 앱으로 점검 정보가 전달됩니다. 현재 상담사 화면의 디자인과 예시 동작은 완료했으며 실제 서버 저장은 연결 중입니다.”
