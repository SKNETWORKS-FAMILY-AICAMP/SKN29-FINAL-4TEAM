# 직원 연락처 전체 목록 화면

작성일: 2026-08-31 · 브랜치: `yena`

확인 링크: [직원 연락처 전체 목록](http://127.0.0.1:5174/consultant/contacts)

## 화면과 사용 방법

- 사이드바의 **직원 연락처** 또는 대시보드 연락처 영역의 **전체 보기**로 진입합니다.
- 이름·부서/지점·직급·내선/전화·이메일을 전체 목록으로 제공합니다. 직원이 먼저 나오고 방문기사가 이어집니다.
- 전체/직원/방문기사 구분, 부서·지점 필터, 검색 버튼 또는 Enter 검색을 지원합니다.
- 이름·부서·직급·이메일과 전화번호를 검색합니다. 전화번호의 공백·괄호·하이픈은 입력하지 않아도 찾을 수 있습니다.
- 필터 초기화와 검색 결과 없음 화면의 전체 목록 복귀를 제공합니다.
- 연락처와 이메일은 각 복사 버튼으로 원문을 복사합니다. 복사가 차단되면 직접 선택해 복사하도록 안내합니다.
- 새로고침은 기존 조회 API를 다시 호출하며 데이터를 수정하지 않습니다.
- 넓은 화면은 표와 고정 열 제목, 좁은 화면은 연락처 카드로 표시합니다. 모든 항목은 세로 스크롤로 확인할 수 있습니다.
- 데이터 없음, 로딩, 네트워크 오류, 로그인 만료, 권한 없음은 별도 상태로 표시합니다.

## 첨부된 페이지 없음 화면에 대한 확인

- 현재 소스의 메뉴 주소와 라우터 경로는 모두 `/consultant/contacts`로 일치합니다.
- 현재 로컬 브라우저에서 메뉴 이동, 대시보드 전체 보기, 직접 주소 재진입이 정상이며 페이지 없음 화면이 나오지 않는 것을 확인했습니다.
- 사용자 첨부 이미지에는 주소가 없어 해당 오류의 정확한 원인은 확정하지 않았습니다. 이전 버전의 번들 또는 다른 접속 주소 여부를 구분하려면 실제 주소 확인이 필요합니다.
- 이번 작업은 커밋·푸시·배포하지 않았습니다. 현재 소스에 있는 새 페이지가 배포본에도 포함됐다고 가정하지 않습니다.

## 데이터와 담당 범위

- 위 로컬 링크는 샘플 데이터 기반 디자인 미리보기입니다. 현재 샘플은 직원 8명·방문기사 4명입니다.
- 기존 `/api/v1/consultant/dashboard`의 직원·방문기사 응답을 사용합니다. 별도 백엔드 API나 DB 직접 연결을 추가하지 않았습니다.
- 연락처 정보는 브라우저 저장소에 별도로 저장하지 않습니다. 복사 버튼을 누른 항목만 클립보드로 전달합니다.
- Backend·Mobile·AI·DB/RDS·Seed·Infra·공용 계약은 변경하지 않았습니다. 이 연락처 화면 보완에 따른 새로운 API·계약 협의 사항은 없습니다.
- 선행 작업과 기존 사용자 변경은 유지했습니다.
