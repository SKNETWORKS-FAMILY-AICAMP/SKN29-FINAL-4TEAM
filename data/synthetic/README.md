# Synthetic Data

실제 개인정보를 포함하지 않는 결정적 시연·테스트 데이터입니다.

## 규모

- 데모 고객 12명, 상담사 2명, 기사 2명
- 제품 모델 1건, 고객 제품 12건, 구독 12건
- 문의 24건: 8개 주제 × 기본·모호·지속/위험 변형
- 대표 문의 후속확인 1건, 방문 연계 관리 이력 1건
- 업무 흐름별 시나리오 부분집합 7파일·37건
- 소음 주제와 근거 없는 IoT fallback 포함

## 구조

- `scenarios/`: 전체 시나리오와 업무 흐름별 부분집합
- `fixtures/`: 사용자·제품·문의·상담·방문·후속확인·관리 이력·감사 이벤트
- `expected/`: 상태 전이·근거·안전·인계 기대 결과

모든 ID와 시각은 `tools/build_step4.py`가 결정적으로 생성합니다.
