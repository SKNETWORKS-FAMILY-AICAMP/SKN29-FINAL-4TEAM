## 6. 남은 후속 항목

P0 완주를 막지는 않지만 다음 항목은 후속 P1/P2로 분리한다.

1. **Mobile 재진입 P1**: 실제 구독 API가 진행 문의 요약을 제공하지 않아 홈 복귀나 앱 재시작 뒤 동일 문의를 다시 여는 경로가 없다. 현재 P0는 연속 Navigation 및 명시적 동일 ID 최종 조회로 검증했다.
2. **Idempotency Key 영속화 P2**: Mobile 상담 요청 Key는 앱 프로세스 메모리에만 유지된다. 서버 처리 후 응답 유실과 앱 프로세스 재시작이 동시에 발생하는 복구에는 영속 Store가 필요하다.
3. **운영환경 Gate**: 팀 PostgreSQL에서 원자 선점 row-lock, 물리 Android 기기에서 네트워크·화면 조작을 재검증한다.
4. **Vector 일반 경로**: 이번 실제 AI 증거는 승인된 누수 안전 규칙 경로다. 로컬 pgvector가 필요한 일반 검색 비교 실험은 PM 결정대로 E2E 이후 수행한다.
