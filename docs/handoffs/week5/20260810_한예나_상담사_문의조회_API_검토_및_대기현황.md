## 1. 완료된 작업 내용

### API 연결 구조

- `GET /api/v1/inquiries` 목록 조회용 Remote Repository를 준비했다.
- `GET /api/v1/inquiries/{id}` 상세 조회용 Remote Repository를 준비했다.
- 공통 HTTP Client를 사용하고 경로는 `/inquiries*`로 연결했다.
- Remote 실패 시 Mock으로 자동 전환되지 않도록 분리했다.
- 목록 Query는 계약에 있는 항목만 전송한다.
  - `q`
  - `status`
  - `risk_level`
  - `priority`
  - `from`, `to`
  - `sort`
  - `page`, `size`
- Web 전용 `assignee`, `consultation` 값은 Backend에 보내지 않는다.

### DTO·Mapper

- API의 `snake_case` 응답과 Web의 `camelCase` 화면 값을 분리했다.
- 위험도 소문자 값을 Remote 화면에서 처리하도록 연결했다.
- Backend 우선순위 `LOW`를 Web 타입과 표시 기준에 추가했다.
- `operation_id`, `requires_confirmation` 등 Action 필드를 Web 형식으로 변환했다.
- 목록의 `page_info`, `status_counts`, `waiting_seconds`를 화면에 연결했다.
- 상세의 다음 Section을 타입과 Mapper에 반영했다.
  - 문의·고객
  - 제품·구독·관리 정보
  - 증상·문진 답변
  - 사용 안내·제한 기능
  - 상태 변경 이력
  - Workflow·`allowed_actions`
  - Section 부분 오류

### 화면 처리

- 목록·상세 Loading·Empty·Error·Forbidden·Retry 상태를 연결했다.
- 상세 404는 미존재·타 상담사 배정 여부를 구분하지 않고 동일하게 안내한다.
- 오류에 Correlation ID가 있으면 화면 문의용 확인 번호로 표시한다.
- `recent_care_date: null`은 `관리 이력 없음`으로 표시한다.
- `usage_guidance_message: null`이면 안내 문구를 표시하지 않는다.
- `restricted_functions: []`는 `제한 없음`이 아니라 `제한 정보 미제공`으로 표시한다.
- `consultation: null`, `visit: null`은 불필요가 아니라 `아직 제공되지 않음`으로 표시한다.
- `allowed_actions`는 이름만 확인하고 상담·방문 쓰기 API가 준비될 때까지 실행 버튼을 만들지 않는다.
- 관리 유형은 Web Mapper에서 표시명으로 변환하며 특정 샘플 값 하나로 고정하지 않는다.

### 개인정보·금지 항목

- 목록에는 마스킹된 고객명만 사용한다.
- 상세에는 Backend가 허용한 합성 고객명·합성 전화번호만 사용한다.
- Remote 상세 ViewModel에는 주소·이메일·계약번호·Serial·내부 DB ID를 추가하지 않았다.
- Backend 응답에 없는 값을 기존 Mock이나 다른 고객 API로 보충하지 않는다.
- CUSTOMER용 `/api/v1/me/subscriptions`를 상담사 화면에서 사용하지 않는다.
- Evidence·AI 내부 Metadata를 이번 조회 응답에 섞지 않는다.

### 자동 검증

- Remote 상세 계약·Null·부분 오류·버튼 제한 테스트를 추가했다.
- 403과 404를 구분하는 Query 상태 테스트를 추가했다.
- Remote 실패 시 Mock 자동 전환 금지 테스트를 유지했다.

## 3. 아직 하면 안 되는 작업

- 기존 Mock 삭제
- 공용 서버에 이미 배포됐다고 가정한 완료 처리
- 상담·방문 쓰기 요청 연결
- `allowed_actions`만 보고 실행 버튼 활성화
- Mock의 상담·방문·주소 값을 Remote 응답에 섞어 표시
- 전화번호 검색이나 고객명 복원
- `/api/v1/me/subscriptions`를 상담사 화면에 재사용

## 5. 최종 정리

Web에서 단독으로 할 수 있는 계약 검토와 코드 준비는 완료했다. Backend 읽기 Runtime은 최지용 님의 로컬에서 구현·검증됐지만 아직 Commit·Push·배포되지 않았다. 따라서 현재는 Mock을 유지하고, 공유 가능한 Backend Commit과 실행환경이 전달될 때까지 실제 연결 완료 판정과 Remote Smoke를 대기한다.
