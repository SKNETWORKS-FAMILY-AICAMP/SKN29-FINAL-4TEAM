## 2. 현재 검증 경계

- 최신 구조는 `customer-app`, `technician-app`, `core` 3모듈이며 Wrapper JAR이 저장소에 포함됐다.
- 작성자 기록상 Core·고객 단위 테스트, Connected Compose UI 테스트, 고객·기사 Debug APK와 실기기 설치가 성공했다.
- 고객·기사 Demo Login HTTP 200과 공개 UUID Token 흐름을 실제 Backend에서 확인한 기록이 있다.
- 최종 보조 검증 로그는 기존 V3 성공 산출물을 재사용하면서 Backend·Device를 `SKIPPED`했으므로 실제 실행 기록과 구분한다.
- 이번 독립 실행은 Gradle 배포본 다운로드와 SDK 접근 뒤 `:core:compileDebugJavaWithJavac`의 `Provider has no value`에서 실패했다. 작성자 성공 기록을 부정하지 않지만 다른 팀원 재현 완료로 보지 않는다.
