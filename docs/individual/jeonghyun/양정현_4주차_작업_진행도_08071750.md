## 3. 4주차 필수 업무별 평가

### 3.1 모바일 기준선 재검증·계약 정합성 복구 — 80%

- 완료·근거: [Mobile Closeout T-056](../../../mobile/docs/week4-post-presentation/2026-08-07_mobile_week4_closeout_t056.md), [Owner Scope Closeout T-057](../../../mobile/docs/week4-post-presentation/2026-08-07_mobile_owner_scope_closeout_t057.md), [검증 Script](../../../mobile/scripts/verify-t057-mobile-owner-closeout.ps1), [공통 Repository](../../../mobile/core/src/main/java/com/skn29/watercare/core/repository/Repositories.kt). 계약 밖 기능을 `준비 중`으로 막고 실제·Fixture 경계를 정리했다.
- 미완료: 현재 HEAD의 Core·Customer·Technician Test와 두 APK Build가 이번 환경에서 Gradle Provider 오류로 완료되지 않았다. 최소 Compose UI Test도 없다.
- 완료 방법: Android SDK·JDK·Gradle/AGP/Kotlin Version 조합을 README와 `local.properties` 예시로 고정하고 `verify-build.bat`을 Clean 환경에서 재실행한다.
- 별도 확인: Owner 환경의 PASS 로그·APK Hash와 현재 HEAD 일치 여부, Emulator/실단말 설치 결과가 필요하다.

### 3.2 고객 홈·제품·구독 실제 API 연동 — 35%

- 완료·근거: [Customer Home](../../../mobile/customer-app/src/main/java/com/skn29/watercare/customer/feature/customer/home/CustomerHomeScreen.kt), [Backend Capability 검사](../../../mobile/scripts/check-backend-runtime-capabilities-t057.ps1), [Customer Repository](../../../mobile/core/src/main/java/com/skn29/watercare/core/repository/CustomerCareRepository.kt). Remote/Fake 경계와 미지원 기능 비활성화는 명확하다.
- 미완료: Backend에 제품·구독·케어 이력 Runtime Endpoint가 없어 Remote Mode에서도 실제 고객 홈 데이터를 조회하지 못한다.
- 완료 방법: Backend의 목록·상세 Runtime 제공 후 DTO·Repository를 연결하고 Fake 위임을 제거한 통합 Test를 작성한다.
- 별도 확인: 최지용의 Endpoint 제공 일정, 계정별 소유권/404 정책을 확인해야 한다.

### 3.3 문의 생성·증상 제출·상태 충돌 실제 연동 — 85%

- 완료·근거: [Remote Repository](../../../mobile/core/src/main/java/com/skn29/watercare/core/repository/Repositories.kt), [취소 멱등 Key Store](../../../mobile/core/src/main/java/com/skn29/watercare/core/repository/CancelIdempotencyKeyStore.kt), [멱등 Test](../../../mobile/core/src/test/java/com/skn29/watercare/core/repository/CancelIdempotencyKeyStoreTest.kt), [증상 입력 화면](../../../mobile/customer-app/src/main/java/com/skn29/watercare/customer/feature/customer/intake/SymptomIntakeScreen.kt). 문의 생성·증상 제출과 동일 취소 재시도 Key 보존 코드가 있다.
