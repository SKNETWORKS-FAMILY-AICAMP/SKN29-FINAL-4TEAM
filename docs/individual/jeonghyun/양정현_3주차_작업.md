# 11. 최종 요약

3주차에는 Android 프로젝트의 기본 구조를 만드는 단계에서 출발해, 고객용·방문기사용 앱을 분리하고 실제 Backend Demo 인증, 고객 최소 흐름, 위험 안내, 디자인, 테스트, APK 빌드와 실기기 설치까지 진행했다.

특히 7월 29일 정적 점검에서 확인된 구조·상태·테스트 부족 문제를 바탕으로 7월 30일부터 모바일을 기능 기반 구조로 재구축했고, 7월 31일에는 Demo 데이터와 실제 인증을 연결한 뒤 전체 화면을 리디자인하고 빌드·테스트·설치를 완료했다.

4주차에는 이번 주에 이미 완료한 **프로젝트 구조, 기본 고객 화면, Demo 로그인, 디자인, 기본 테스트·빌드**를 다시 작성하지 않는다. 4주차의 핵심은 실제 API 계약으로 교체하고, 미구현 고객·기사 후속 기능과 지도·QR/OCR·위치 기능을 최종 구조에 통합하며, PR과 협업 검수를 완료하는 것이다.
