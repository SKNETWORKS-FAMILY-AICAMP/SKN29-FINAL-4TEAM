## 6. 권장 완료 순서

1. **계약 우선:** PM·Backend와 공개 응답 DTO 및 이벤트 매핑을 확정하고 JSON Schema/Pydantic/예시/테스트를 먼저 일치시킨다.
2. **환경 재현:** `pyproject.toml`, Lock, README, 환경별 설정을 작성해 새 환경에서 서버와 테스트를 실행 가능하게 한다.
3. **실제 검색 수직 흐름:** 공통 Data Loader→bge-m3→pgvector 적재→Exact Search→Metadata Filter→38페이지/혼입 테스트를 한 경로로 연결한다.
4. **안전 Graph:** LangGraph Conditional Branch로 위험·근거 없음·일반 경로를 분리하고 최종 Guard를 적용한다.
5. **통합 검증:** 최상위 계약·안전·Backend-AI·Vector Store 테스트와 실제 평가 보고서를 생성한다.
6. **교차 검토와 인계:** Backend·Data·Web·Mobile 확인 결과, 보안 로그 검수, PR Reviewer와 미완료/4주차 범위를 공식 문서에 남긴다.

현재 가장 중요한 선행 과제는 **응답 계약 정합화**와 **Mock 검색을 실제 bge-m3·pgvector 검색으로 교체하는 것**이다. 이 두 항목이 해결되기 전에는 나머지 테스트가 통과하더라도 3주차 AI·RAG 과업 전체를 완료로 판정하기 어렵다.
