- State Machine은 `v1.0.0 / TEAM_APPROVED`, 대표 E2E는 14단계다.
- Data Owner Review는 `APPROVED`; Data 61건·QA 2회·E2E 17/17 기록이 있다.
- Backend는 418건 기록, OpenAPI 9·Runtime 7·OpenAPI-only 2, T-005 12/32다.

- Web은 상담사 3단계 업무 UI까지 병합됐으나 최신 Commit의 Test/Lint/Build 재실행 기록과 실제 상담 API가 없다.
