## 4. 실행하지 못한 검증과 이유

- 실제 Backend→AI Uvicorn Socket 공동 Gate는 AI Mock Server 미기동으로 실행하지 않았다.
- TEAM_INTEGRATION Role Credential Gate는 본 독립 DB 검증 범위에 포함되지 않아 실행하지 않았다.
- 두 항목은 T-016·T-017C·T-018 PASS로 세지 않았으며 별도 Gate로 남긴다.

## 5. 발견했지만 수정하지 않은 관할 밖 문제

- `backend/tests/unit/evidence/test_ai_canonical_evidence_import.py`의 PostgreSQL apply Test Helper가 `--confirm-database`를 전달하지 않는다.
- 실제 명령은 PostgreSQL apply 시 해당 인자를 의도적으로 필수화하므로, 현재 Test Helper는 SQLite에서는 통과하지만 PostgreSQL 전체 회귀에서 실패한다.
- Backend Test는 최지용 주관 영역이므로 김은진 역할에서 소스를 수정하지 않았다.

## 6. 필요한 담당자 인계

- 최지용: 위 Test Helper가 `connection.settings_dict["NAME"]`의 실제 pytest 자동 DB명을 `--confirm-database`로 전달하도록 수정하고 PostgreSQL 전체 회귀를 재실행해야 한다.
- 최지용·이동윤: 실제 Backend→AI Uvicorn Socket 공동 Gate를 AI Mock Server 준비 후 별도 검증해야 한다.
- 김은진 DevOps·최지용 DB: TEAM_INTEGRATION Role Credential Gate를 통합환경 전용 Credential 준비 후 별도 검증해야 한다.
- PM: 본 APPROVE는 세 기술 Gate에 한정하며 WBS 상태 갱신은 별도 판정한다.

## 7. 남은 위험과 확인 필요 항목

- Harness 수정이 저장소에 반영되기 전에는 보정 없는 PostgreSQL 전체 회귀가 동일 2건으로 다시 실패한다.
- 외부 AI Socket과 TEAM_INTEGRATION Role Credential은 이번 결과로 검증되지 않았다.
- 보존한 QA DB는 독립 검증 증거용이며 운영·공유 DB로 사용하지 않는다.
