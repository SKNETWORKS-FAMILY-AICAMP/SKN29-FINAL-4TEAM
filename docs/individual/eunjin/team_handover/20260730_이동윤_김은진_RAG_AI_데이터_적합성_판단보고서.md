## 4. 데이터 구조 적합성

7개 청크는 청크 식별, 제품 범위 제한, 출처 추적, 검색 본문, 안전 판단,
안전 응답과 사용 허용 판단에 필요한 필드를 갖고 있다.

| Data 필드 | AI/pgvector 사용 |
|---|---|
| `chunk_id` | UPSERT 및 검색 결과의 고유 키 |
| `document_id` | 문서 출처 필터와 추적 |
| `chunk_text` | 임베딩 생성 대상 본문 |
| `exact_sales_code` | 정확 모델 필터 |
| `product_generation` | 세대 필터 |
| `verification_status` | 공식 검증 여부 판정 |
| `scope_role` | MVP 사용 허용 판정 |
| `source_file_sha256` | 원본 동일성 추적 |
| `page_refs` | 답변 근거 페이지 반환 |
| `safe_actions` / `prohibited_actions` | 안전 답변 생성 및 차단 근거 |

`TEXT_AND_VISUAL_VERIFIED`를 AI 저장 계층의 `official_verified` 의미로
변환해 사용한다. 공통 코드
`contracts/codes/verification-statuses.yaml`이 비어 있으므로 이 의미
매핑은 Data·AI·공통 계약 담당자가 확정해야 한다.

## 5. 콘텐츠 적합성과 범위

포함된 주제는 물이 나오지 않음, 냉수가 차갑지 않음, 소음, 누수,
맛·냄새 이상, 출수량 감소, 순간 온수 안전이다.

현재 7개 청크는 한 문서의 37~39페이지에 집중되어 있으므로 다음
범위에는 충분하지 않다.

- JAC104D 전체 사용 설명서 질의
- 설치·관리·소모품·기능 전 범위 질의

- IAC425·IAC506 등 다른 모델 답변
- 공식 매뉴얼과 정확 모델이 확인되지 않은 FAQ 답변
- 운영 환경 전체 제품군 대상 범용 RAG

청크 단위 content Hash를 추가한다. 현재 MVP 차단 사항은 아니다.
