## 2. 해석 원칙

- Archive의 상태·테스트 수치·파일 경로는 현재 상태가 아닐 수 있다.
- 현재 구현 판정은 활성 계약, Django Model·Migration, Runtime과 최신
  검증 결과를 사용한다.
- Archive 문서를 활성 문서에 복사해 중복 원천을 만들지 않는다.
- 비밀값·실제 고객 데이터·개인 PC 절대경로를 추가하지 않는다.

## 3. 보호 정책

`20260802_문서통합_원본/**`은 통합 당시 원문을 보존하는 묶음이다.
오탈자나 낡은 표현이 있더라도 직접 고치지 않고 활성 문서에서
교정한다. 새 역사 자료는 보호 묶음 밖에 별도 파일로 추가한다.
