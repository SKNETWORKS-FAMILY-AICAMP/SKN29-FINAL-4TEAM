# OpenAPI 59·47·12 Runtime 읽기 전용 감사

> 작성일: 2026-08-24
>
> 기준: `origin/main@e99cf78faa58a40f2cec49281119c437b594e470`
>
> 담당: 최지용 (Backend·DB)

## 1. 결론

최신 `main`의 공개 OpenAPI는 59개 Operation을 선언한다. 이 중 실제 Django
Route와 View Method까지 연결된 항목은 47개이고, 12개는 아직 Runtime이 없다.

```text
openapi_operations=59
runtime_operations=47
not_implemented_operations=12
audit_test=3 passed
```

59개 계약 존재를 59개 Runtime 완료로 해석하면 안 된다.

## 2. 미구현 12개

### P1-A G2 동결 계약 9개

- 계약 이메일 확인 Challenge 생성·검증
- 합성 계약고객 회원가입
- ID/PW 로그인
- 아이디 찾기 Challenge 생성·검증
- 비밀번호 재설정 Challenge 생성·검증·확정

이 9개는 `x-contract-status=CONFIRMED`지만
`x-runtime-status=NOT_IMPLEMENTED`다. G3 Model·Migration·Seed 기반은 이
Runtime의 선행조건일 뿐 API 구현 완료가 아니다.

### 기존 후속 Runtime 3개

- `PATCH /inquiries/{id}/questionnaire`
- `POST /visits/{visit_id}/start`
- `POST /visits/{visit_id}/complete`

첫 항목은 Route Method가 없고, 방문 Start·Complete는 공개 계약만 있으며
실제 View가 없다.

## 3. 검증 근거

```powershell
python -m pytest `
  backend/tests/api/test_openapi_runtime_coverage.py -q
```

결과는 `3 passed`다. 검사는 다음을 동시에 확인한다.

1. Operation 59개와 `operationId` 59개가 유일함
2. 47개가 예상 Route·View·HTTP Method로 해석됨
3. P1-A 9개가 명시적으로 `NOT_IMPLEMENTED`임
4. 기존 OpenAPI-only 3개에 Runtime Method가 없음

## 4. 안전한 후속 순서

1. Data Crosswalk가 G3 Source Hash 변경을 승인한다.
2. G3 Model·Migration·Seed를 병합한다.
3. P1-A Runtime을 Additive Slice로 구현한다.
4. Mobile과 실제 HTTP Smoke를 수행한다.
5. 12개 수치는 Runtime 구현 때만 테스트와 함께 줄인다.

이번 감사에서는 OpenAPI·Backend Runtime·Data·Mobile 코드를 수정하지 않았다.
