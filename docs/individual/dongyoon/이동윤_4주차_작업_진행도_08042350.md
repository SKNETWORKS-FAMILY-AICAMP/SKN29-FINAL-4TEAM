## 2. 이번 점검에서 직접 확인한 실행·증거 경계

### 2.1 코드와 저장된 결과로 확인된 내용

- AI 요청·응답 계약은 JSON Schema `1.1.0`과 Pydantic 모델로 구성돼 있고 저장된 공식 후보 보고서에는 계약 Parity `PASS`가 기록돼 있다.
- `SymptomStructurer`, `MissingFieldChecker`, `FollowUpQuestionGenerator`, `DuplicateQuestionGuard`가 실제 `SingleRAGPipeline`의 Structuring·Missing Fields Stage에 연결돼 있다.
- 위험 입력은 추가 질문을 건너뛰고 안전 분기로 이동하도록 구현돼 있다.
- 전체 HTTP Timeout 30초, 단계별 Timeout, Backend 자동 재시도 0회, AI 검색 Provider 내부 최대 1회 재시도가 설정과 Runtime에 연결돼 있다.
- 검색 결과 0건, Vector 설정 누락, 일시 검색 오류, 비재시도 오류, Timeout을 서로 다른 상태·오류로 다루는 테스트가 있다.
- `BAAI/bge-m3`, Revision `5617a9f61b028005a4858fdac845db406aefb181`, 1024차원, 정규화, pgvector Cosine Exact Search 설정이 코드·Index Manifest·보고서에서 일치한다.
- 격리 PostgreSQL 16.14·pgvector 0.8.6에서 12/12 PASS, Recall@5 `1.0`, MRR `0.8857`, 금지 Hit 0 결과가 저장돼 있다.
- 현재 공식 후보 문서는 직접 학습·파인튜닝 미수행, 팀 DB 미검증, Backend Adapter 미연결, Graph DB 미사용을 명시한다.
