## 3. Runtime 명령·환경변수 확인

QA 통합환경의 AI Runtime 기동 명령은 현재 main에서도 유효하다. 저장소 Root에서
보호 Loader와 Uvicorn을 같은 PowerShell Process로 실행한다.

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -Command '& {
  . .\scripts\deployment\import_team_integration_env.ps1 `
    -Role AI -RequireOpenAIKey | Out-Null

  & .\ai\.venv\Scripts\python.exe -B -m uvicorn `
    ai.app.main:app `
    --host 127.0.0.1 `
    --port 8001
}'
```

AI Process 필수 환경변수 이름은 다음과 같다.

```text
OPENAI_API_KEY
AI_LLM_MODEL
AI_VECTOR_DSN
AI_EMBEDDING_REVISION
AI_VECTOR_TABLE_NAME
```

실제 값은 보호 Loader가 Process에만 주입한다. Secret·DSN 원문은 문서·채팅·Git·로그에
기록하지 않는다.

같은 Host의 Backend G1-B 저장 Metadata는 다음 배포 설정과 정렬해야 한다.

```ini
AI_SERVICE_BASE_URL=http://127.0.0.1:8001
AI_SERVICE_MODE=local
AI_MODEL_PROVIDER=openai
AI_MODEL_NAME=gpt-4.1-mini
AI_PROMPT_VERSION=customer_guidance/v2
```

위 Backend 변수는 AI Process의 Secret 주입 목록과 별개다.

## 4. Runtime·Correlation 준비 확인

현재 이동윤 Host에서 실행 중인 AI Runtime의 `/health`는 HTTP 200이며
`config_loaded=true`다. 이는 기동·설정 적재 증거이고 공동 QA Host의 실제 pgvector
Query나 Backend 저장 결과를 대신하지 않는다.

공동실행에서 같은 Correlation ID로 확인할 AI 로그 Event는 준비돼 있다.

```text
analysis_started
llm_guidance_completed
analysis_completed
```

확인 근거:

- `ai/app/interfaces/http/routes/analysis_routes.py`
- `ai/app/integrations/llm/token_usage.py`
- `ai/app/generation/customer_guidance/prompt_identity.py`
- `ai/app/integrations/llm/llm_client.py`
- `ai/configs/backend_integration_environment.json`
- `scripts/deployment/import_team_integration_env.ps1`
- `infra/docker/compose/team-integration/README.md`

공동 증거에는 Event 이름, Correlation 일치, 실행 상태, 모델, Prompt Version과 Token
사용 여부만 남긴다. Raw Prompt·고객 입력·Evidence 원문·Vector·Secret은 남기지 않는다.
