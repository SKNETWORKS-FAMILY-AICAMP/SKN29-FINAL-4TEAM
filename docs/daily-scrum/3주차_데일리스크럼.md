## 7월 27일 (월) - 담당 영역별 개발 기준 정리 및 핵심 기능 구현 진행
* **진행 업무**
  * 팀원별 업무 범위와 공통 상태·API 규칙 정리
  * 모바일·웹 핵심 화면 구현 및 ERD·API·합성 데이터 정합성 검토
* **주요 작업 내용**
  * PM은 공통 업무 흐름과 완료 기준을 정리하고, 모바일은 카카오맵 경로 및 이동 기능을 구현함
  * 백엔드·DB는 ERD와 API 명세를 수정하고, AI·RAG는 변경 지침을 기반으로 선행 개발 범위를 검토함
  * 데이터·QA·DevOps는 합성 데이터와 E2E 계약 불일치를 수정하고, 웹은 상담사 문의 목록·상세·방문 전환 화면과 공통 로딩 UI를 구현함

## 7월 28일 (화) - 디렉토리 구조 수정 및 충돌사항 수정
* **진행 업무**
  * 팀원별 각자 맡은 업무 진행 및 충돌 수정
* **주요 작업 내용**
  * PM - 모바일 디렉토리 분리, git 충돌 관리
  * 데이터·QA·DevOps - 승인 필요없는 데이터 정리 및 합의 대기중
  * 모바일개발 - 모바일 디렉토리 바꾸면서 JDK 다시 설치. 앱 아이콘 변경
  * 백엔드 - 장고 Postgresql 마이그레이션 할 수 있도록 문서 정리 , state machine 과 충돌하는 부분 수정
  * 프론트 - 상담사 화면 및 기능 구현 완료, 로딩/오류/권한필요/부분실패 상황에 뜨는 화면 구현
  금주 중 관리자 화면 및 기능 구현 예정, 백엔드 준비 후 실제 API, JWT 연동 및 E2E 테스트 예정
  * AI/RAG - 안전 규칙 분류기 & 출력 가드레일 엔진 구축 , FastAPI 실행 환경 , 임베딩과 검색기 구축. RAG 기준선 및 최소 오케스트레이터 프롬프트 작성 . 현재 검증중
