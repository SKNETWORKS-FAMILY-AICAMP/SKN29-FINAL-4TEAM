## 8월 3일 (월) - 기존 구현 검증 및 Web–Backend 실제 연동 기준 정리

* **진행 업무**
  * Backend·Data·Web의 기존 구현을 독립적으로 재검증하고, 실제 데이터와 연습용 데이터의 경계를 정리함
  * 상담·방문 화면의 실제 API 연동 범위와 권한·개인정보·공식 근거 공개 기준을 검토함
* **주요 작업 내용**
  * 별도 PostgreSQL QA 환경에서 Migration과 시연 계정 생성을 확인하고, 로그인·권한·문의 접근 제한을 포함한 Backend·Data 전체 테스트와 State Machine 계약 검증을 수행함
  * Web은 설치·테스트·코드 검사·빌드를 독립 재현하고, 실제 데이터와 연습용 데이터를 구분했으며 사용하지 않는 파일 약 20개를 삭제해 코드 구조를 정리함
  * 상담·방문 Mock 화면을 실제 API로 전환하기 위한 조회·상태 전환·오류 처리 계약을 검토하고, 상담사·운영 관리자·현장기사별 개인정보 노출 범위와 공식 근거 표시 기준을 정리함
  * 팀원별 4주차 업무 지침서와 코드 리뷰노트, 중간발표 기술 자료를 작성하고, WBS의 인증·권한 작업 상태와 후속 검증 범위를 갱신함
