# 1. 수집 데이터

## 1.1 수집 데이터 개요

WaterCare의 공식 근거와 합성 업무 데이터를 현재 데이터 버전 0.9.0 기준으로 정리했다.

공식 원본은 저장소에 보관하지 않고 외부 보존본의 경로·버전·페이지·SHA-256 계보만 관리한다.

MVP RAG는 WPUJAC104DWH의 D세대 REV.00 p.37~39만 승인하며 IAC425·IAC506·S세대·모델 미검증 FAQ는 차단한다.

|---|---|---|---|---|
| MVP 공식 사용설명서 | WPUJAC104DWH / JAC104D·JCC104D REV.00 44쪽 | 제품 증상·안전 조치의 1차 근거 | MVP RAG 7청크·페이지 출처 | SK인텔릭스서비스 / 외부 보존본 / 재배포 권한 미확인 |
