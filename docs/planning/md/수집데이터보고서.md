# 1. 수집 데이터

## 1.1 수집 데이터 개요

WaterBridge는 정수기 구독 고객의 증상 안내와 상담 인계에 사용할 공식 근거 데이터, 평가 데이터, 합성 업무 데이터를 관리한다. 공식 원본 PDF는 저장소에 넣지 않고 외부 보존본의 출처·버전·페이지·SHA-256 계보만 관리한다.

현재 제품 범위는 아래 3개 정확 판매 코드다. 검색 전에 `exact_sales_code`로 필터링하며 다른 모델 문서로 대체하거나 교차 모델 fallback을 허용하지 않는다.

| 정확 판매 코드 | 공식 문서 범위 | 페이지 데이터 | 승인 검색 청크 | 상태 |
|---|---|---:|---:|---|
| `WPUJAC104DWH` | WPU-JAC104D·WPU-JCC104D REV.00 | 44쪽 | 15 | 3모델 인계 대상 |
| `WPUIAC425SNW` | WPU-IAC425 REV.02 | 52쪽 | 19 | 3모델 인계 대상 |
| `WPUIAC606SNW` | WPU-IAC606 REV.00 | 48쪽 | 19 | 3모델 인계 대상 |
| 합계 | 공식 사용설명서 3종 | 144쪽 | 53 | 데이터 인계 완료, 런타임 활성화 별도 Gate |

`WPU-IAC506`은 구형·제외 모델이다. 신규 검색 데이터, 제품 화면, 시연 데이터에 사용하지 않는다.

# 2. 수집 방법 및 자동화 절차

## 2.1 수집 방식

| 수집 방식 | 선택 | 설명 |
|---|---:|---|
| 문서 파일 수집(PDF·FAQ) | ☑ | 공식 사용설명서·고객지원 자료의 출처와 버전을 확인한다. |
| 공식 웹 조회·외부 보존본 검증 | ☑ | URL·수집일·파일 해시·페이지 수를 기록한다. |
| 합성 데이터 생성 | ☑ | 실제 개인정보 없이 고객·문의·상담·상태 이력을 생성한다. |
| 무차별 웹 크롤링 | ☐ | 출처·권리·모델 적용 범위를 확인할 수 없는 자료는 수집하지 않는다. |

## 2.2 수집·정제 도구와 예외 처리

| 항목 | 내용 |
|---|---|
| 사용 언어 / 라이브러리 | Python 3, `json`, `csv`, `hashlib`, `pathlib`; 외부 PDF 확인 시 `pypdf` |
| 자동화 | `data/tools/pipeline.py`가 선언형 설정으로 processed·RAG·synthetic·QA·Manifest를 생성한다. 현재 선언 데이터셋 버전은 `1.3.0`이다. |
| 원본 처리 | 공식 PDF 원문은 Git에 저장하지 않는다. 경로·버전·SHA-256·페이지·검수 기록만 보존한다. |
| 오류 처리 | Schema·해시·페이지·참조·정확 판매 코드 불일치 시 실패 처리한다. 다른 모델 근거로 자동 대체하지 않는다. |
| 활성화 조건 | 인덱스 건수·해시 일치, Backend 적재 QA, AI 읽기 전용 조회, 정확 모델 필터, 교차 모델 차단을 모두 확인한 뒤 Runtime을 활성화한다. |

## 2.3 수집·저장 흐름

```text
공식 자료 확인
→ 출처·버전·SHA-256 Inventory
→ 페이지별 텍스트·Source Span 추출
→ 사람 검수와 정확 판매 코드 부여
→ Parent/Child Chunk·Evidence Group 생성
→ Schema·참조·해시·중복·결정성 QA
→ AI/Backend 인계 Manifest
→ Backend 적재 및 AI SELECT_ONLY 조회 Gate
→ 정확 모델 검색·안전·근거 평가 후 활성화
```

# 5. 데이터 품질 및 정합성 관리

| 검증 영역 | 기준 |
|---|---|
| 고유성 | 원본 SHA-256, `document_id+page`, `child_id`, `evidence_group_id`, `scenario_id`를 종류별 고유키로 사용한다. |
| 계보 | 모든 검색 청크가 정확 판매 코드, 문서 버전, 페이지, Source Span, 원문 해시로 역추적되어야 한다. |

| 안전성 | 위험도를 생성 전에 판정하고, 위험·근거 부재·검증 실패는 자가조치 생성보다 상담 전환 또는 fail-closed를 우선한다. |

| 재현성 | 동일 설정 재생성 시 Canonical 파일 drift가 없어야 하며 Manifest 건수·SHA-256을 비교한다. |
| Runtime Gate | 데이터 QA, Backend 적재, 읽기 전용 View, AI 검색, 모델 혼입 음성 케이스를 분리 검증한다. |
