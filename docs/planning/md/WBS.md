# 정수기 구독 고객 케어 및 A/S 업무 지원 시스템

## WBS (Work Breakdown Structure) v2.4

> 기획서, 화면설계서 통합본 v10, 요구사항정의서 v2.2 104건 및 수집데이터보고서의 정합성을 반영한 WBS이다.
> 최초 작성 기준일: 2026-08-07
> 최종 현행화: 2026-08-28 (원격 `main` 문서 HEAD `7a12f676437dd077c8e29e3c7163673163bd1cf3`; 코드·Runtime 검증 기준 `95f90f843124373fc97c6cd9e258b1427e0cbde8`)
> 범위 변경: 핵심 MVP를 합성 계약고객 인증 → 고객 앱 → AI Safety/RAG → 상담사 Web → 고객 상담 결과 확인으로 재고정한다. 방문기사 현장 처리와 운영자 통합 대시보드는 P1 후속 범위다.
> 판정 원칙: 과거 후보 SHA의 PASS는 이력으로만 인정한다. 최신 `main`의 동일 SHA 수직 E2E, P1-A 독립 QA, Browser E2E와 배포 후 기능 Smoke 전에는 최종 통합 완료로 승격하지 않는다.
