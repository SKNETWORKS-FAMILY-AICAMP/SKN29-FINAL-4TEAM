## 3. 4주차 업무 100% 완료를 위해 각 담당자에게 요청할 내용

### 윤승혁 — PM·기술 통합

- 상담·방문 기능의 개발 순서와 완료 날짜를 확정해 주세요.
- 상태별 가능한 행동과 상담 완료·방문 전환 기준을 승인해 주세요.
- 행동 23개와 실제 서버 기능·담당 코드를 연결한 표를 확정해 주세요.
- 5주차 인계 담당자와 목표일을 승인해 주세요.

필요 결과: 행동 연결표, 담당자·목표일, 최종 WBS 승인.

### 최지용 — 백엔드·DB

- 상담사 문의 목록·상세의 서버 주소와 검색·페이지 조건을 제공해 주세요.
- 목록·상세·상담·방문 결과 형식과 오류 형식을 확정해 주세요.
- 상담 시작·임시 저장·완료가 실제 DB에 저장되게 해 주세요.
- 방문 요청·기사 후보·희망일·확정일이 실제 DB에 저장되게 해 주세요.
- 상태 버전, 중복 저장 방지값, 요청 추적값을 실제 응답에 포함해 주세요.
- 고객 이름·연락처·주소·상담 메모의 역할별 공개 범위를 확정해 주세요.

필요 결과: 실행 가능한 서버 기능, 결과 예시, 실제 DB 저장 기록, 오류 확인 기록.

### 이동윤 — AI·RAG

- Web에 공개할 공식 근거 항목과 숨겨야 할 내부 항목을 확정해 주세요.
- AI 초안·공식 근거·오류 표시가 화면 기준과 맞는지 확인해 주세요.
- 제품 모델이 섞이지 않는지, 근거가 없을 때 답변을 멈추는지 최신 환경에서 확인해 주세요.
- 최지용 담당자와 AI 결과가 백엔드에 저장되고 Web으로 전달되는 형식을 확정해 주세요.

필요 결과: 공개용 근거 형식, 최신 AI 검사 결과, 백엔드 전달 결과 예시.

### 양정현 — 모바일 앱

- 고객 앱과 기사 앱이 사용하는 방문 희망일·확정일·일정 상태 이름을 Web·백엔드와 맞춰 주세요.
- 배정된 기사만 방문 건을 볼 수 있는지 실제 서버에서 확인해 주세요.
- 고객 → 상담사 → 기사로 전달되는 정보 중 모바일에서 필요한 값을 확정해 주세요.
- 최신 고객·기사 앱 빌드 결과를 공유해 주세요.

필요 결과: 공통 방문 데이터 형식, 기사 권한 확인 결과, 최신 앱 빌드 기록.

### 김은진 — 데이터·QA·DevOps

- 공개용 공식 근거 항목과 개인정보 숨김 기준을 이동윤·최지용 담당자와 확인해 주세요.
- 실제 서버 연결 후 목록·상세·상담·방문 흐름을 검사해 주세요.
- 권한 오류, 동시 수정, 중복 저장, 입력 오류, AI 오류 상황을 확인해 주세요.
- 화면 요청 추적값과 백엔드 로그·DB 결과가 이어지는지 확인해 주세요.
- 전체 결과와 남은 문제를 최종 테스트 보고서로 정리해 주세요.

필요 결과: 실제 연결 검사 결과, 오류 검사 결과, 최종 테스트 보고서.
