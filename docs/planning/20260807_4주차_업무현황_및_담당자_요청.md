### 윤승혁 — PM·기술 통합

- 행동 23개와 실제 서버 기능·담당 코드를 연결한 표를 확정해 주세요.
- 상담·방문 서버 기능 11개의 개발 순서와 완료 날짜를 정해 주세요.
- 고객 → 상담사 → 방문기사 전체 흐름의 담당자와 확인 순서를 정해 주세요.
- 팀원별 결과를 확인하고 최종 WBS와 4주차 완료 여부를 승인해 주세요.

필요 결과: 행동 연결표, 담당자·일정 확정표, 최종 WBS 승인.

### 최지용 — 백엔드·DB

- 팀에서 실행 가능한 Python 환경을 맞추고 전체 테스트 결과를 공유해 주세요.
- 제품·구독과 케어 이력의 실제 서버 기능을 구현해 주세요.
- 상담·방문 관련 서버 기능 11개를 구현해 주세요.
- 추가 답변, 자가조치, AI 결과, 상담 결과, 방문 일정이 DB에 저장되게 해 주세요.
- 이동윤 담당자와 AI 실제 호출·결과 확인·DB 저장을 연결해 주세요.
- Web 연결에 필요한 서버 주소와 입력·결과·오류 형식을 공유해 주세요.

필요 결과: 전체 테스트 통과 기록, 서버 기능 문서, 실제 DB 저장 결과.

### 이동윤 — AI·RAG

- 현재 코드와 팀 DB에서 AI 테스트와 검색 평가를 다시 실행해 주세요.
- 제품 모델이 섞이지 않는지, 근거가 없을 때 답변을 멈추는지 확인해 주세요.
- 증상 정리와 추가 질문 결과 형식을 백엔드 담당자와 확정해 주세요.
- 시간 초과나 오류가 난 뒤 상담으로 넘어가는 흐름을 실제 연결로 확인해 주세요.
- 최지용 담당자와 AI 요청 → 결과 → DB 저장 흐름을 끝까지 확인해 주세요.

필요 결과: 최신 AI 테스트 결과, 검색 평가 결과, 백엔드 연결 기록.

### 양정현 — 모바일 앱

- Android SDK 설정 문제를 해결하고 고객·기사 앱의 최신 빌드 결과를 공유해 주세요.
- 고객 앱의 제품 조회, AI 안내, 상담 요청을 실제 서버와 연결해 주세요.
- 기사 앱의 방문 목록과 사전 점검 내용을 실제 서버와 연결해 주세요.
- 배정된 기사만 방문 건을 볼 수 있고 다른 기사는 볼 수 없는지 확인해 주세요.

필요 결과: 최신 앱 빌드 통과 기록, 실제 서버 연결 화면, 기사 권한 확인 결과.

### 김은진 — 데이터·QA·DevOps

- 백엔드와 모바일 실행 환경 문제 해결을 지원하고 실행 방법을 문서로 남겨 주세요.

- 권한 오류, 중복 요청, 동시 수정, AI 오류 상황도 확인해 주세요.
- 영역별 결과와 남은 문제를 모아 최종 테스트 결과 보고서를 작성해 주세요.

필요 결과: 전체 흐름 검사 결과, 오류 확인 결과, 최종 테스트 결과 보고서.
