## 2. 평가 방법

각 항목에 아래 네 가지 중 하나를 표시한다.

| 표시 | 의미 |
|---|---|
| 정상 | 기대한 화면과 기능이 문제없이 작동함 |
| 일부 문제 | 다음 단계로 진행할 수 있지만 표시나 사용성이 불편함 |
| 실패 | 기능이 작동하지 않거나 다음 단계로 진행할 수 없음 |
| 확인 못함 | 환경이나 준비 부족으로 평가하지 못함 |

`필수` 항목은 핵심 시연의 성공 여부를 결정한다. 필수 항목을 확인하지 못한 경우 최종 결과를 `통과`로 판정하지 않는다.

## 3. 시연에 사용할 상황

아래 문장을 고객 증상으로 사용한다.

이 항목은 진행자가 환경을 준비한 경우에만 확인한다. 핵심 시연 성공을 위해 오류를 억지로 만들 필요는 없다.

| 번호 | 확인할 상황 | 정상적으로 보이는 모습 | 결과 | 메모 |

| 31 | 상담 요청 버튼을 빠르게 두 번 누름 | 같은 요청이 두 건 생기지 않음 |  |  |
| 32 | 상담 기록 작성 중 화면을 새로고침함 | 이미 저장된 내용은 다시 나타나고, 저장하지 않은 내용이 저장됐다고 속이지 않음 |  |  |
| 33 | 서버 연결이 끊긴 상태에서 조회함 | 가짜 성공 화면을 보여주지 않고 연결 문제를 안내함 |  |  |
| 34 | 사용할 수 있는 공식 자료가 없는 문의를 확인함 | 임의 근거를 만들지 않고 상담 확인이 필요하다고 안내함 |  |  |

전화 문의 등록은 핵심 고객→AI→상담 시연과 별도로 평가한다. 이 항목이 실패하더라도 핵심 시연 결과와 섞지 않고 별도 기록한다.

| 번호 | 외부 사용자가 확인할 내용 | 정상적으로 보이는 모습 | 결과 | 메모 |

| 36 | 고객명 또는 연락처 일부로 고객을 찾을 수 있는가? | 개인정보 전체를 노출하지 않으면서 검색 결과가 표시됨 |  |  |

| 38 | 고객을 선택하면 제품·구독 정보가 채워지는가? | 선택한 고객의 사용 제품이 자동으로 표시됨 |  |  |

| 40 | 등록한 문의를 목록과 상세에서 확인할 수 있는가? | 입력 내용이 같은 문의로 이어지고 상담 처리를 시작할 수 있음 |  |  |

## 7. 이번 평가에서 제외하는 기능

아래 기능은 이번 핵심 시연의 통과 여부에 포함하지 않는다.

- 방문기사 배정·방문 일정·방문 완료
- 상담 완료 이후 최종 해결 확정
- 관리자 화면과 통계 대시보드
- AI 모델·검색 방식 비교 실험
- 공식 근거 상세 화면의 추가 디자인

상담 완료 직후에는 `완전히 해결됨`이 아니라 **처리 결과 확인·최종 완료 대기**로 표시되는 것이 현재 시연의 정상 종료다.
