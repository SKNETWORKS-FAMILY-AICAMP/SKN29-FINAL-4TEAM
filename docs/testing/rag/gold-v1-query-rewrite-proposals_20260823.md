# Gold v1 질문 자연화 제안

> 기준일: 2026-08-24 KST
> 원본 상태: `UNREVIEWED_DRAFT`
> 질문 1차 검수 상태: `GOLD_QUERY_PRIMARY_REVIEW_COMPLETED_HUMAN_SIGNOFF_PENDING`

## 목적

Gold 60건의 질문을 실제 고객이 채팅에 입력할 수 있는 표현으로 다시 구성했다.
원본 `ai/evaluation/datasets/gold/rag_gold_v1.jsonl`은 수정하지 않았고, 제안
Pack은 원본 SHA-256을 고정한 별도 데이터다.

질문 문구가 바뀌면 Evidence, `ANY/ALL/NONE`, 위험도와 안내 정책도 달라질 수
있으므로 기존 자동 검수와 0045·0049의 사람 결정은 질문 확정 후 재검수 대상으로
유지한다.

## 1차 결정 결과

| 결정 | 건수 |
|---|---:|
| `PROPOSED_QUERY_APPROVED` | 23 |
| `WORDING_CHANGE_APPROVED` | 36 |
| `QUERY_REJECTION_PROPOSED` | 1 |

60건 모두 결정됐고 의미 변경 표시는 19건이다. `RAGV2-GOLD-0001`은 무출수
자가 점검 질문에서 빠른 수리 요청으로 바뀐 점을 의미 변경으로 바로잡았다.
`RAGV2-GOLD-0040`은 질문 제외
제안으로 기록했지만 원본에서 삭제하지 않았다. 사람 최종 서명과 Gold 병합은
계속 `PENDING`이다.

## 작성 원칙

- 정책 용어와 평가자 표현을 고객 질문에서 제거한다.
- 답에 포함될 원수 밸브, 플러그 분리 같은 조치를 질문에서 미리 제시하지 않는다.
- `COLLOQUIAL`, `TYPO_ABBREVIATION`, `COMPOUND`, `NO_EVIDENCE`,
  `CROSS_PRODUCT` 변형 목적은 유지한다.
- 안전 문장은 단순 상황 서술에서 사용자의 조치 문의로 바꾼다.
- 원문 근거가 예방만 지원하는 0047은 화상 후 처치가 아니라 예방 질문으로
  의도를 명확히 한다.
- 질문 확정 전 Gold 원본, 최종 Case ID, Split과 Dataset Version을 변경하지
  않는다.

## 우선 재검수 대상

다음 Case는 자연화 과정에서 의도를 구체화했거나 현재 Evidence 정책에 영향을 줄
가능성이 크다.

- 0007, 0014, 0015, 0019, 0029
- 0039
- 0045, 0047, 0049
- 0055

0016과 0017은 질문 의도는 유지했지만 매뉴얼의 상담 조건에 비해 현재 안내 정책이
약할 가능성이 있어 라벨 재검수가 필요하다.

## 승인 제한

질문 문구 1차 결정은 완료됐지만 Gold 승인이나 병합을 의미하지 않는다. Evidence
라벨을 다시 검수하고, 이동윤 영역의 독립적인 2차 검수와 병합 협의를 거쳐야 한다.

## 질문 확정 후 라벨 재검수

별도 `gold_v1_post_query_label_revalidation_packet.json`에서 확정 질문 60건을
원본 Gold 라벨과 다시 대조했다.

| 판정 | 건수 |
|---|---:|
| `SUPPORTED` | 33 |
| `CHANGE_PROPOSED` | 7 |
| `SOURCE_CHECK_REQUIRED` | 19 |
| `REJECT_PROPOSED` | 1 |

변경 제안은 0001·0016·0017·0028·0033의 상담 전환, 0039의 단일 무출수
Evidence 전환, 0047의 예방 질문에 맞춘 위험도·안내 정책 조정이다. 후속 1차
검수는 사람 결정 8건, AI 근거 대조 처리 18건, 기존 라벨 유지 33건, 질문 제외
제안 1건으로 60건 모두 처리됐다. 1차 미결 항목은 0건이지만 모든 행의
`human_signoff_status`와 독립 2차 검수 상태는 `PENDING`이다.

0043은 젖은 손으로 이미 플러그를 만졌다는 위험 행동을 전제로 하지 않도록
플러그 주변 물기와 전원 코드 과열을 발견한 상황으로 다시 교정했다.
0052는 구매 경로가 P028에 존재하므로 구매 의사를 제거하고 현재 필터 판매
가격만 묻는 순수 무근거 질문으로 교정했다.
