# 검증 결과 보관 규칙

- 원시 로그에는 비밀값·Token·개인정보·DB 접속 문자열을 남기지 않는다.
- 결과 문서에는 실행 commit, 환경, 명령, 건수, 오류와 재현 방법을 기록한다.
- 사용자 확인과 실행 로그 검증을 구분한다.
- Backend·AI 담당자의 증빙이 없으면 `PENDING_EVIDENCE`를 유지한다.
