다만 위 결과를 다음 전체 사용자 흐름의 완료로 확대할 수는 없다.

```text

→ 실제 Backend / PostgreSQL
→ 실제 3모델 pgvector / 생성형 LLM
→ Guidance / Evidence
→ Consultation Handoff
→ 상담사 Web 처리 완료
```
