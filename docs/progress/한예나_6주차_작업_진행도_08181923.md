3. 상담 시작→기록 저장→완료→Refresh 후 동일 상태를 실제 Backend와 대조한다.
4. 401·403·404·409·5xx, 입력 보존, 권한 없는 데이터 비노출을 Browser에서 실행한다.
5. 1920×1080·노트북·긴 Text·Loading/Empty/Error 화면을 사람이 확인한 뒤 Layout Freeze를 선언한다.
