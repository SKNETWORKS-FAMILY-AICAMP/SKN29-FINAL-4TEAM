- Production Build는 환경변수 누락 시 Mock으로 전환하지 않고 실제 API 경로를 기본으로 사용한다.

- 본 갱신에서 최신 `a29ec0f` 기준 Web 전체 **34 files / 155 tests PASS**를 독립 재확인했다. 첨부 보고서의 lint·typecheck·production build도 PASS다.
- 첨부 보고서의 상담 E2E 표적은 **6 files / 29 tests PASS**다.
- Backend 미기동 시 가짜 목록이나 Mock 성공으로 바꾸지 않고 실제 오류 화면을 표시하는 Fail-closed Browser 경계가 확인됐다.

완료하려면 현재 후보 SHA의 `.env`에 공용 API URL을 설정하고 상담사 로그인→목록→상세→Action 가능 여부를 Browser Network와 함께 기록한다.
