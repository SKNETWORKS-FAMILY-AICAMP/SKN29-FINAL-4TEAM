2. 실제 추가 질문이 있는 Inquiry에서 `SUBMIT_ANSWERS` 성공과 질문 소진 후 Guidance 이동을 확인한다.
3. Guidance·Evidence 표시, 상담 요청, Web 상담 완료, Mobile 최신 상태 재조회를 같은 Inquiry로 기록한다.
4. 최신 main에서 `verify-build.bat`, Release APK, AndroidTest를 다시 실행한다.
5. 키보드 CTA, 실제 입력 회전 보존, Portrait·Landscape Clipping, Font 130% 겹침을 사람이 확인한다.
