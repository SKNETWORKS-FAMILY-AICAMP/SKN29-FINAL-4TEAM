# 고객 홈 데이터 모드 적용 가이드

## 1. 작업 목적

고객 홈의 합성 데이터와 실제 Backend 문의 요청이 한 화면에서 조용히 섞이지 않도록 실행 모드를 명시적으로 분리한다.

현재 Backend Runtime에는 고객 제품·구독 조회와 고객용 AI 안내 조회 Endpoint가 등록되어 있지 않다. 따라서 임의 Endpoint를 추가하지 않고 다음 기준을 사용한다.

- `REMOTE`: 문의 생성·증상 제출은 실제 Backend를 사용한다.
- `REMOTE`의 고객 홈·안내는 합성 Fixture임을 화면에 표시한다.
- `FAKE`: 홈·문의·안내 전체를 합성 데이터로 실행한다.
- Remote 요청이 실패해도 Fake 성공 결과로 자동 전환하지 않는다.

## 2. local.properties 설정

`mobile/local.properties`에 다음 값을 추가한다.

```properties
CUSTOMER_CARE_MODE=REMOTE
DEMO_SUBSCRIPTION_ID=<Demo 고객의 실제 활성 구독 Public UUID>
SHOW_DEVELOPER_TOOLS=false
```

### 설정값 설명

| 설정 | 값 | 설명 |
| --- | --- | --- |
| `CUSTOMER_CARE_MODE` | `REMOTE` | 문의 생성·증상 제출 실제 API 사용 |
| `CUSTOMER_CARE_MODE` | `FAKE` | 전체 고객 흐름 합성 데이터 사용 |
| `DEMO_SUBSCRIPTION_ID` | UUID | Remote 문의 생성에 사용할 Demo 고객 활성 구독 Public UUID |
| `SHOW_DEVELOPER_TOOLS` | `false` | 발표 화면에서 상태별 개발 검증 메뉴 숨김 |
| `SHOW_DEVELOPER_TOOLS` | `true` | 개발 중 상태별 안내 화면 검증 메뉴 표시 |

실제 구독 UUID는 개인 `local.properties`에만 저장한다. 예제 문서, 커밋, 로그, 화면 캡처에는 실제 값을 남기지 않는다.

## 3. 문의 시작 가능 조건

### Remote 모드

다음 조건을 모두 만족해야 문진 시작 버튼이 활성화된다.

1. Demo 로그인이 완료되어 있다.
2. `DEMO_SUBSCRIPTION_ID`가 정규 UUID 형식이다.
3. 고객 홈 Fixture를 정상적으로 불러왔다.
4. 오프라인 화면 미리보기 상태가 아니다.

UUID가 없거나 잘못된 경우 문진 시작 버튼을 비활성화하고 설정 안내를 표시한다. 고정 Fixture UUID로 실제 Backend 요청을 보내지 않는다.

### Fake 모드

Backend 연결 없이 합성 고객 흐름을 확인할 수 있다. 발표 중 Backend 장애가 발생했을 때만 명시적인 Fallback으로 사용한다.

## 4. 화면 표시 기준

고객 홈 상단에 현재 데이터 출처를 다음처럼 표시한다.

- `Remote 모드 · 문의 생성·제출 실제 API · 홈·안내 합성 Fixture`
- `Remote 모드 · Demo 구독 UUID 미설정 · 홈·안내 합성 Fixture`
- `오프라인 미리보기 · 홈·안내 합성 Fixture · 문의 전송 차단`
- `Demo Mock 모드 · 홈·문의·안내 합성 데이터`

개발 검증 도구는 `SHOW_DEVELOPER_TOOLS=true`일 때만 표시한다. 발표용 Debug APK에서는 기본값 `false`를 유지한다.

## 5. 검증 명령

```powershell
cd mobile
.\gradlew.bat :core:test :customer-app:testDebugUnitTest :customer-app:assembleDebug --no-daemon
```

추가 확인 항목:

1. Remote 모드에서 UUID 미설정 시 문진 시작 버튼이 비활성화되는지 확인한다.
2. 실제 Demo 구독 UUID 설정 후 문의 생성·증상 제출이 성공하는지 확인한다.
3. 오프라인 미리보기에서 실제 문의 요청이 전송되지 않는지 확인한다.
4. Fake 모드에서 전체 합성 흐름이 동작하는지 확인한다.
5. 발표용 설정에서 개발 검증 도구가 숨겨지는지 확인한다.

## 6. 현재 제한사항

- 고객 제품·구독 조회는 아직 실제 Backend Endpoint와 연결되지 않았다.
- 고객 안내와 공식 근거 조회는 아직 실제 Backend·AI Endpoint와 연결되지 않았다.
- 상담 요청 Endpoint가 준비되기 전까지 상담 요청은 활성 성공 동작으로 표현하지 않는다.
- 제품·구독 Endpoint가 제공되면 `DEMO_SUBSCRIPTION_ID` 직접 설정을 제거하고 Backend 응답의 Public UUID를 사용한다.
