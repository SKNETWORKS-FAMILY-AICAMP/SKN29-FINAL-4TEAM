# 2026-08-04 모바일 제한사항

## 1. Runtime Endpoint 제한

현재 모바일에서 실제로 사용할 수 있는 Runtime Endpoint는 인증·사용자 조회·문의 생성·증상 제출·문의 취소 범위다.

다음 Endpoint는 아직 모바일 발표 기본 흐름에서 사용할 수 없다.

- 고객 제품·구독 목록 조회
- 고객 홈 케어 이력 조회
- 문의별 AI 안내 결과 조회
- 공식 근거 조회
- 상담 요청
- 상담 진행 상태 조회
- 방문 일정 조회
- 기사 방문 목록·상세 조회

Endpoint가 제공되지 않은 기능은 임의 URL이나 가짜 성공 Callback으로 구현하지 않는다.

## 2. 고객 홈 제한

- 고객 홈 제품·구독은 합성 Fixture다.
- REMOTE 모드에서는 실제 Demo 고객의 활성 구독 Public UUID가 `local.properties`에 필요하다.
- Demo 구독 UUID가 없으면 실제 문의 시작을 차단한다.
- UUID는 소스·문서·로그·Git에 기록하지 않는다.

## 3. 고객 안내 제한

- AI 안내와 Evidence는 현재 Demo Fixture다.
- AI 내부 Prompt, 검색 점수, `chunk_id`, 내부 파일 경로, 검색 원문 전체를 표시하지 않는다.
- 근거 없음과 알 수 없는 코드는 안전한 상담 대기 상태로 처리한다.
- 상담 요청 Runtime Endpoint가 없으므로 활성 상담 성공으로 처리하지 않는다.

## 4. 발표 환경 제한

- 실제 기기에서 PC Backend를 사용할 때 `adb reverse tcp:8000 tcp:8000`이 필요하다.
- Emulator에서는 `127.0.0.1`이 아니라 `10.0.2.2`를 사용한다.
- 발표 Wi-Fi, 방화벽, USB 디버깅 상태에 따라 실시간 시연이 실패할 수 있다.
- 발표 전 APK, 화면 캡처, 짧은 Fallback 영상이 모두 필요하다.

## 5. 4주차 제외 기능

다음 기능은 고객 최소 흐름과 발표 기준선을 완료하기 전에는 추가하지 않는다.

- 지도
- GPS
- QR
- OCR
- 기사 위치 추적
- 방문 시작·도착·완료
- FCM
- Room
- WorkManager

지도·GPS·QR이 필요하면 `personal/mobile-extension`에서만 진행하고 `jeonghyun` 발표 기준선과 섞지 않는다.

## 6. 보안·개인정보 제한

- Token, Demo 구독 UUID, 실제 고객 정보, API 비밀값을 Git에 커밋하지 않는다.
- 운영 데이터와 합성 데이터를 화면과 발표에서 구분한다.
- Logcat과 검증 결과에 고객 식별자 전체를 남기지 않는다.
- APK는 Debug 용도이며 운영 배포본으로 표현하지 않는다.
