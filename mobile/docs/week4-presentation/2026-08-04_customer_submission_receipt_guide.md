# 고객 문의 실제 접수 정보 표시 보강

## 목적

고객 문진 제출 이후 실제 Backend 응답과 AI 안내 Fixture가 섞여 보이지 않도록 화면 출처를 분리한다.

## 변경 내용

- 문의 생성·증상 제출 성공 응답의 실제 문의번호를 안내 화면까지 전달한다.
- 실제 상태 코드와 한글 상태명, 상태 버전, Backend 허용 행동을 접수 완료 카드에 표시한다.
- 멱등 재사용 응답이면 기존 접수 결과를 재사용했다는 문구를 표시한다.
- AI 안내 조회 API가 준비되지 않은 상태에서도 실제 문의번호를 `BACKEND-INQUIRY`로 덮어쓰지 않는다.
- 고객 홈의 제품·구독·진행 중 문의 Fixture는 기존처럼 합성 데이터임을 표시한다.

## 발표 시 설명

> 문의 생성과 증상 제출은 실제 Backend API 응답입니다. 접수 완료 카드에는 Backend가 반환한 문의번호, 상태, 상태 버전과 허용 행동을 그대로 표시합니다. 제품·구독 홈과 AI 안내 조회는 아직 Endpoint가 제공되지 않아 합성 Fixture 또는 준비 중 상태로 명시합니다.

## 재검증 순서

1. Backend 서버와 실제 Android 단말을 준비한다.
2. Demo 로그인 후 고객 홈에서 `REMOTE` 모드를 확인한다.
3. `문진 시작`을 눌러 실제 증상을 입력한다.
4. `안내 결과 확인`을 눌러 문의를 제출한다.
5. 안전 안내 상단의 `문의 접수 완료` 카드에서 실제 문의번호·상태·버전을 확인한다.
6. 아래 안전 안내 영역이 근거 없음 상태에서 임의 자가조치를 표시하지 않는지 확인한다.
