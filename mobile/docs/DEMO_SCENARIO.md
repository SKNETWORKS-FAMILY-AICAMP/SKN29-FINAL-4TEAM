# 발표 시연 시나리오

## QR 경로

1. 고객이 `QR 촬영으로 오류 확인`을 누른다.
2. 정수기 QR을 촬영한다.
3. 제품 코드 `WPUJAC104DWH`, 오류 코드 `E01`이 확인된다.
4. 앱이 `급수 이상`과 방문 점검 필요 결과를 표시한다.
5. 고객이 방문기사를 요청한다.
6. `김정수 기사` 배정 정보를 확인한다.
7. 위치 확인 화면에서 기사 마커가 카카오맵을 따라 이동한다.
8. 이동 문구가 차량 → 도보 → 도착 → 점검 중으로 변경된다.

## 문진 경로

1. 고객이 `문진으로 오류 확인`을 누른다.
2. 출수량 저하와 증상 설명을 제출한다.
3. 앱이 `급수·출수 이상`으로 구조화한다.
4. 이후 방문 요청과 기사 이동 흐름은 QR 경로와 동일하다.
