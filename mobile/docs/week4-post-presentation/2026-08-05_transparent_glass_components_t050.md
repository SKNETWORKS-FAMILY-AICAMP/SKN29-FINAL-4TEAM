# T-050 투명 Glass 버튼·박스 및 물결 배경 강화

## 목표

물결 배경이 카드 뒤에서 실제로 보이도록 고객용·방문기사용 공용 Compose
컴포넌트의 흰색 면적과 불투명도를 크게 줄인다.

## 투명도 기준

- 물결 배경 이미지: 100%
- 강한 Glass 패널: 흰색 24%
- 일반 Glass 패널: 흰색 14%
- 일반 버튼: 흰색 18%
- 선택 버튼: Accent 28~34%
- 역할 Chip: 흰색 14%
- 상태·빠른 실행 타일: 흰색 14%
- 하단 내비게이션 선택 영역: 흰색 16%
- Glass 테두리: 흰색·Accent 48~78%

## 적용 대상

- 고객 로그인
- 고객 홈
- 방문기사 로그인
- 방문기사 홈
- Backend 상태 카드
- Hero 카드
- 상태 카드
- 빠른 실행 카드
- 제품·방문 상세 카드
- 상단 역할 Chip과 아이콘 버튼
- 하단 내비게이션

## 가독성

- 텍스트는 기존 Ink 계열을 유지한다.
- 카드 테두리는 투명 배경에서도 구분되도록 Iridescent 선을 유지한다.
- 위험 카드는 기존 불투명·위험 색상 정책을 유지한다.
- 카드 그림자는 2dp로 줄여 물결 배경을 가리지 않는다.

## 기능 영향

- 로그인·세션 복원 변경 없음
- 고객 문진·안전 안내 변경 없음
- 방문기사 방문 상세 변경 없음
- Backend·Fixture 구분 변경 없음
- 신규 의존성 없음
- 지도·GPS·QR 추가 없음
