# T-051 완전 투명 Glass 및 핵심 버튼 색상 보정

## 목표

T-050에서 카드 모서리만 투명하게 보이고 내부 흰색 면이 남아 보이는 문제를
보정한다. 고객용·방문기사용 모두 물결 배경이 카드 전체를 통해 보이도록
표면 채움색을 거의 제거한다.

## 공통 Glass 정책

- 강한 패널 표면 Highlight: 4.5%
- 일반 패널 표면 Highlight: 1.8%
- 일반 패널 그림자: 0dp
- 패널 중앙: 완전 투명
- 상태 카드·빠른 실행 카드: 완전 투명에 가까운 표면
- 테두리: 흰색·Accent Iridescent 선만 유지
- 배경 White veil: 1~1.8%

## 고객용 강조 색상

- Primary: `#248CFF`
- Secondary: `#5D6BFF`
- 강조 대상:
  - Backend 다시 확인
  - 고객 Demo 로그인
  - 상세 화면의 주요 실행 버튼
  - 진행률
- 오프라인 미리보기와 보조 버튼은 투명

## 방문기사용 강조 색상

- Primary: `#0FB9AA`
- Secondary: `#42D7C9`
- 강조 대상:
  - Backend 다시 확인
  - 방문기사 Demo 로그인
  - 상세 화면의 주요 실행 버튼
  - 진행률
- 합성 미리보기와 보조 버튼은 투명

## 배경

- 고객용: 선명한 하늘색·파란색·라벤더 물결
- 방문기사용: 민트·아쿠아 물결
- 두 배경 모두 앱 내부 `drawable-nodpi` PNG
- 네트워크 이미지 요청 없음

## 기능 경계

- 로그인·세션 복원 유지
- 고객 문의·안전 안내 유지
- 방문기사 상세 흐름 유지
- Backend·Fixture 구분 유지
- 신규 Android 의존성 없음
- 지도·GPS·QR 추가 없음
