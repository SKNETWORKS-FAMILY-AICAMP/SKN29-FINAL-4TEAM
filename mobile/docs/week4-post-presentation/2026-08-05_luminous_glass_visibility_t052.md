# T-052 Luminous Glass 가시성 보정

## 목표

T-051의 완전 투명 Glass 구조는 유지하되, 카드와 버튼이 배경에 묻히는
문제를 외곽 Glow와 내부 Highlight로 개선한다.

## 패널

- 강한 패널 Glow: 7dp
- 일반 패널 Glow: 4dp
- 외곽선: 흰색·Accent Iridescent 1.65dp
- 내부 상단 Highlight: 44%
- 표면 Highlight:
  - 강한 패널 8.5%
  - 일반 패널 4.0%
- 중앙 영역은 계속 투명 유지

## 버튼

- 주요 버튼 Glow: 8dp
- 보조 버튼 Glow: 3dp
- 고객용 주요 버튼: 하늘색·파란색
- 방문기사용 주요 버튼: 민트·청록색
- 보조 버튼은 투명 상태를 유지하면서 외곽과 내부 빛만 강화

## 상태 및 빠른 실행

- 카드 내부 채움은 7% 이하
- 아이콘·라벨·테두리는 이전보다 선명하게 표시
- 물결 배경은 그대로 보임

## 기능 영향

- 로그인·세션·API 연결 변경 없음
- 고객·방문기사 앱 공통 컴포넌트만 수정
- 신규 Android 의존성 없음
- 지도·GPS·QR 추가 없음
