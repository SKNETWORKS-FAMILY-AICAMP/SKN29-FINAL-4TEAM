# T-047 고객·방문기사 레퍼런스 구조 일치 보정

## 기기 캡처에서 확인한 문제

- 고객용은 Backend 연결 실패 시 기존 로그인 카드가 화면 대부분을 차지했다.
- 방문기사용 하단 메뉴가 스크롤 콘텐츠 안에 있어 첫 화면에서 보이지 않았다.
- Hero 카드와 상태 카드의 높이가 커서 정보 밀도가 낮았다.
- 문자 기호 아이콘이 레퍼런스의 입체 아이콘과 차이가 컸다.
- 고객용과 방문기사용 화면의 공통 구조가 완전히 일치하지 않았다.

## 보정

- 고객 로그인도 Reference Dashboard Scaffold로 교체
- 방문기사 로그인도 동일한 Scaffold 사용
- 고객 홈과 방문기사 홈의 하단 내비게이션 고정
- 고객용 블루·라벤더, 방문기사용 민트·아쿠아 유지
- 31개의 로컬 투명 PNG 아이콘 추가
- Hero 246dp, 상태·액션 타일 112dp
- Samsung Fold 세로 화면 기준 16dp 좌우 여백
- Backend 미연결 시 오프라인 대시보드 미리보기를 강조
- 실제 API와 합성 Fixture 구분 유지

## Kotlin과 TypeScript

- Kotlin + Jetpack Compose: 실제 Android 실행 UI
- TypeScript: 색상·메뉴·레이아웃 수치 계약

## 기능 경계

- 고객 문진 시작과 안전 안내 연결 유지
- 고객 방문 일정은 API 미제공 상태 유지
- 방문기사 방문 상세와 사전 점검 연결 유지
- 경로와 작업 기록은 API 미제공·개인 확장 상태 유지
- Backend 성공을 가장하지 않음
