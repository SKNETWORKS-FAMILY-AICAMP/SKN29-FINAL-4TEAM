# T-054 고대비 물방울 글래스

## 목적

물방울 카드와 버튼이 물결 배경에 묻히는 문제를 해결한다. 투명한 성질은
유지하되 카드와 버튼마다 다른 색상, 광량, 외곽선 강도를 사용해 정보 영역과
실행 영역을 바로 구분할 수 있도록 한다.

## 정보 카드

- 물방울 비대칭 Corner 강화
  - 위쪽 시작 38dp
  - 위쪽 끝 58dp
  - 아래쪽 끝 30dp
  - 아래쪽 시작 48dp
- 강한 카드 표면 Highlight 18%
- 일반 카드 표면 Highlight 11%
- Accent 수분광 14% / 8.5%
- 발광 효과 13dp / 8dp
- Iridescent 외곽선 2dp
- 내부 반사광과 하단 Accent 물방울 광 강화

## 버튼

### 주요 버튼

- 고객용: 하늘색·파란색
- 방문기사용: 민트·청록색
- Primary Fill 최대 98%
- Glow 15dp
- 외곽선 1.7dp
- 흰색 텍스트

### 보조 버튼

- 투명 Glass 유지
- Accent Tint 22%
- Glow 8dp
- Accent 텍스트
- 외곽선 1.5dp
- 정보 카드보다 채도와 반사광이 강함

## 빠른 실행

- 작은 비대칭 물방울 형태 유지
- Accent Tint 최대 18%
- Glow 10dp
- 외곽선 1.7dp
- 정보 상태 박스와 클릭 요소를 명확하게 구분

## 기능 영향

- 로그인·세션 복원 변경 없음
- Backend·Fixture 구분 변경 없음
- 고객 문의·자가조치·안전 안내 변경 없음
- 방문기사 일정·상세 기능 변경 없음
- 신규 Android 의존성 없음
- 지도·GPS·QR 추가 없음
