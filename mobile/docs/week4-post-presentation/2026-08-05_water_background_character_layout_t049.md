# T-049 물결 배경·캐릭터·레이아웃 정밀 보정

## 목표

생성된 고객용·방문기사용 목업의 시각 언어를 실제 Android Kotlin Compose
화면에 반영한다.

## 고객용

- 블루·라벤더 물결 로컬 PNG 배경
- 기존 `mascot_customer` 캐릭터 복구
- 로그인 Hero와 고객 Home Hero에 동일 캐릭터 적용
- Backend 상태를 큰 Glass 카드로 표현
- 버튼과 안내 문구는 카드 폭 안에서만 표시

## 방문기사용

- 민트·아쿠아 물결 로컬 PNG 배경
- 방문기사 도구 이미지는 기존 로컬 자산 유지
- 방문 상태와 빠른 실행을 Glass 카드 구조로 유지
- 긴 문구는 최대 두 줄과 말줄임으로 제한

## 오버플로 방지

- Hero는 고정 비율 Overlay가 아니라 Row + Weight 구조를 사용한다.
- 360dp 미만 화면에서 이미지와 제목 크기를 자동 축소한다.
- 상태 카드 라벨은 최대 두 줄이다.
- 빠른 실행 라벨은 최대 두 줄이다.
- 상세 카드의 제목과 Badge를 세로로 배치한다.
- 상단 앱 제목과 섹션 제목은 한 줄 말줄임을 적용한다.

## 디자인 경계

- 배경 이미지는 앱 내부 로컬 자산이며 네트워크 요청이 없다.
- 신규 Android 의존성을 추가하지 않는다.
- 로그인·문진·안전 안내·방문 상세 흐름은 유지한다.
- Backend와 합성 Fixture의 구분을 유지한다.
- 지도·GPS·QR 기능은 추가하지 않는다.
