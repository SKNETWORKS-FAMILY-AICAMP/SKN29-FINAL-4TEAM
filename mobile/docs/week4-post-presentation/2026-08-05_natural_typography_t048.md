# T-048 고객·방문기사 타이포그래피·아이콘 자연화

## 확인한 문제

- 한글 제목에 Black·ExtraBold가 반복되어 화면이 지나치게 무거웠다.
- 제목 자간이 -1.3sp까지 적용되어 한글 획이 답답하게 붙어 보였다.
- `♙`, `♢`, `⌕`, `⌄` 문자 기호가 Android 기기 글꼴에 따라 서로 다른
  서체로 렌더링됐다.
- Hero 카드의 이름과 인사말이 과도하게 강조됐다.
- Glass 카드 그림자와 흰색 Fill이 강해 글자와 카드가 경쟁했다.

## 보정 기준

- 별도 폰트 파일을 추가하지 않는다.
- Android 기본 SansSerif 한글 글꼴을 명시한다.
- 제목은 Bold·SemiBold, 본문은 Normal·Medium을 사용한다.
- 한글 음수 자간은 -0.3sp 이하로 제한한다.
- 제목·본문·라벨의 줄높이를 용도별로 다시 설정한다.
- 상단 역할·알림·지원 아이콘은 문자 기호 대신 Compose Canvas로 그린다.
- Hero 카드 높이는 226dp, 상태 카드는 106dp, 실행 카드는 108dp로 조정한다.
- 카드 그림자는 6dp, Radius는 24dp로 정리한다.

## 기능 영향

- 로그인·세션 복원 변경 없음
- 고객 문진·안심 케어 연결 변경 없음
- 방문기사 방문 상세 연결 변경 없음
- Backend와 합성 Fixture 구분 변경 없음
- API 미제공 기능 활성화 없음
