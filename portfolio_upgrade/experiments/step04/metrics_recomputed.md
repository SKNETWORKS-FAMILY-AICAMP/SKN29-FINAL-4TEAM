# WaterBridge 실습 04 — 독립 계산한 검색 지표

> 실습용 8개 문단·10개 상관된 질문. 실제 서비스 성능이 아님.

| 방식 | Hit@1 | Hit@3 | MRR@3 | 행 누락 | 검색 오류 |
|---|---:|---:|---:|---:|---:|
| overlap | 4/10 | 6/10 | 0.4667 | 0 | 0 |
| bm25 | 6/10 | 7/10 | 0.6333 | 0 | 0 |
| embedding | 6/10 | 8/10 | 0.6833 | 0 | 0 |

## 주의

- 모든 질문을 분모에 포함하며, 오류·결과 없음의 RR은 0점이다.
- `acceptable_chunk_ids`는 **하나라도 맞으면 성공**이라는 대체 정답 목록이다. 모든 근거가 필수인 Recall과는 다르다.
- 실제 상위 K개를 저장한 경우에만 Hit@K/MRR@K를 계산할 수 있다.
