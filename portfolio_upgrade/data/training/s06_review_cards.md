# S06 — 공식 PDF 직접 검수 카드 (15건)

> **2026-10-30 PDF 직접 검수 완료:** 15건 모두 원본 설명서 SHA-256 일치 및 해당 원문 확인. **행동 라벨 13건 확인, 2건은 ASK/ANSWER 재판정 대기.**
> 이 문서는 **정답 내용 검수 기록**이며 실제 고객 상담 기록이나 SFT 학습 허가·모델 성능 검증이 아니다. `examples_v0.jsonl`은 원본으로 보존한다.

## 이 문서를 읽는 법

1. 고객 발화를 읽고 **지금 확인된 조건**을 찾는다.
2. `ANSWER / ASK / ESCALATE` 중 왜 해당 행동인지 본다.
3. 어떤 PDF 몇 쪽에서 어떤 근거를 확인했는지 본다.
4. 정답 예문에서 **반드시 들어갈 안내**와 **빼야 할 주장**을 확인한다.

## 검수 요약

## 다음 단계와 사용 제한

- **PDF 근거를 확인한 것**과 **학습에 사용할 수 있는 것**은 별개다. `source_use_limit`는 기존 오프라인 평가용 기록 그대로 보존한다.
- 현재 `input.evidence=[]`이므로 학습·추론에서 제공할 근거 본문, 인용 ID, 검색 조건을 S08에서 별도 고정해야 한다.
- 원본 S04의 두 버튼 문의는 PDF만으로 답변 가능하므로, `ASK` 라벨을 자동 승인하지 않고 S07/S08 의사결정 대상에 남긴다.
- 기존 Dev 6 / Holdout 6은 추후 학습 예시에 사용하지 않는다.
- SFT에 투입 가능한 예시는 아직 **0건**이며, 이 단계는 **정답 설계·검수**다.
