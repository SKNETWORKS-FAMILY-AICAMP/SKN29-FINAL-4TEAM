# S11 — 사용설명서 유래 자료의 학습 이용 범위 검토

> **현재 결론: 미확정 (`NOT_APPROVED`).** 이 문서는 저작권 판단을 확정하는 법률 의견서가 아니라 **자료 출처와 이용 근거를 기록하기 위한 체크리스트**다. 기존 S07 26건을 SFT에 넣으라는 승인이 아니다.

## 왜 이 확인이 필요한가?

Qwen3-1.7B 모델의 Apache-2.0 라이선스는 **모델 사용 조건**이다. 별개로 제조사 사용설명서의 텍스트·도표·가공 데이터에는 **자료 자체의 이용 조건**이 있을 수 있다. 공개 PDF를 내려받을 수 있다는 사실만으로 AI 학습·가공 데이터 재배포가 전부 허용된다고 단정하지 않는다.

한국 문화체육관광부와 한국저작권위원회는 **2026년 2월** 생성형 AI 학습과 저작권법상 공정이용에 관한 안내서를 발표했다. 따라서 'AI 학습은 일률적으로 금지' 또는 '비상업적 연구이므로 일률적으로 허용'이라는 단정 모두 피해야 한다. 특정 자료와 이용 형태에 대해 **허락·이용약관·적용 가능한 법적 근거**를 개별적으로 확인한다.

- 공식 안내서: https://www.copyright.or.kr/information-materials/publication/research-report/view.do?brdctsno=55211
- 문체부 2026-05-18 발표: https://www.mcst.go.kr/english/policy/pressView.jsp?pSeq=635
- 국가법령정보센터 현행 저작권법(2026-10-29 시행): https://www.law.go.kr/LSW/lsInfoP.do?lsiSeq=285693
- SK매직 서비스센터 제품 사용설명서 안내: https://service.skmagic.com/web/search/searchMain.do

이 링크들만으로 **SK매직이 SFT 학습을 허락했다는 증거가 되지는 않는다.**

## 자료별로 확인할 항목

| 항목 | 현재 확인 상태 | 확인에 필요한 증거 |
|---|---|---|
| IAC425 REV.02 PDF에서 유래한 설명·정답 | 미확정 | 원저작자·해당 자료 이용 조건·학습 허락 또는 법적 검토 기록 |
| IAC606 REV.00 PDF에서 유래한 설명·정답 | 미확정 | 위와 동일 |
| JAC104/JCC104 REV.00 PDF에서 유래한 설명·정답 | 미확정 | 위와 동일 |
| S04 합성 시나리오·팀 가공 데이터 | 미확정 | 작성자·팀 산출물 이용 허락·외부 문서 의존성과 유통 범위 |
| S10 순수 가상 `SIM-P100/P200` 실습 자료 | 독립 경로 | 가상 원문을 직접 작성했는지, 제3자 매뉴얼 복제가 없는지 확인 |

**추가로 판단할 네 가지 사용 행위는 서로 다르다.** (1) 개인 로컬 실험에 파일을 입력하는 것, (2) GPU 학습에 사용하고 어댑터를 저장하는 것, (3) 학습 자료·체크포인트를 GitHub에 공개하는 것, (4) 실제 서비스를 운영하는 것. 한 행위의 이용 근거가 다른 행위까지 자동으로 포함하는 것은 아니다.

## 현재 선택할 수 있는 개발 경로

**A. 근거 확인 후 WaterBridge 원문 기반 SFT** — 권리 범위와 문서·팀 데이터 출처를 확인하고, 검색 근거·안전 조건도 모두 충족한 사례만 별도 승인하는 경로. 아직 시작하지 않는다.

**B. 자체 작성 가상 정책 기반의 행동 SFT** — 가상 제품/가상 근거를 직접 창작해 `ANSWER/ASK/ESCALATE/EXPLAIN_UNSUPPORTED`의 판단·JSON 구조 학습을 진행하는 경로. 실제 WaterBridge Dev와의 점수 비교는 *도메인 전이 진단*일 뿐, 실제 매뉴얼 내용의 학습 성과로 주장할 수 없다.

지금은 **B 경로의 데이터 확장 설계를 병행하되, A 경로도 승인 가능성을 확인**한다. 승인 전 `training_ready=false`를 코드에서 자동으로 바꾸지 않는다. 필요하면 권리자 또는 전문가에게 범위를 구체적으로 문의한다.
