## 오픈북 규칙

**오픈북으로 풀어도 된다.** 개념과 숫자를 외웠는지가 아니라, **검색 결과·코드·공식 근거를 근거로 스스로 설명하고 판단할 수 있는지**를 평가한다.

- **참고 가능:** 저장소의 `overview.md`, `M0.md`, `M1.md`, `docs/plan_v4.md`, 관련 Python 코드, 실험 JSON/JSONL, 공식 사용설명서. 필요하면 일반 기술 문서도 검색 가능하다.
- **권장:** 답안을 **자신의 말**로 작성하고, 참고한 코드·문서·실험 파일이 있으면 문항 답안 끝에 경로를 적는다. AI의 완성 답안을 그대로 가져오는 방식은 실력 진단의 의미를 떨어뜨린다.
- **구분할 것:** `[실측]` 실제 실행 결과 / `[코드 확인]` 소스에서 확인한 사실 / `[추론]` 가능한 원인 / `[미검증]` 아직 검증하지 않은 주장.
- **계산 문제:** 식과 중간 계산을 반드시 적는다. 결과만 쓰면 부분점수가 줄어들 수 있다.
- **답안 작성법:** 각 소문항의 `> [여기에 답안을 작성하세요]` 문장을 **자신의 답으로 교체**하면 된다. 길이가 부족하면 같은 소문항 아래에 줄을 추가한다.
- **제출:** 완성된 `.md` 파일을 이 대화에 올리면 문항별 점수·오류·꼬리질문을 채점한다.
