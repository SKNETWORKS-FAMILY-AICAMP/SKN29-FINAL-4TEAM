# S09 — 첫 SFT 기반 모델 선택 기록 (후보 결정, 로컬 검증 전)

## 0. 한눈에 보기

- **1차 후보:** [`Qwen/Qwen3-1.7B`](https://huggingface.co/Qwen/Qwen3-1.7B)
- **모델 카드 라이선스:** Apache-2.0 (2026-10-31 확인). **사용설명서·합성 데이터에 대한 학습/재배포 권한과는 별개.**
- **작업 범위:** 한국어 고객지원 문장 + 구조화된 행동 JSON + 검색으로 제공된 공식 근거.
- **아직 한 적 없는 것:** 체크포인트 버전 고정, 실제 토크나이저 20건 점검, 모델 추론, GPU 학습, SFT 성능 측정.

## 1. 왜 Qwen3-1.7B 후보인가?

1. 기존 계획의 **1~3B급 소형 지시문 모델** 범위에 부합하고, 텍스트 전용 모델이므로 멀티모달 구성 부담이 없다.
2. 일반적인 한국어 고객 문의 및 구조화된 출력을 대상으로 먼저 시도할 수 있다. **성능이 충분하다는 것은 아직 입증하지 않았다.**
3. Hugging Face의 Transformers·vLLM 안내가 있다. API/로컬/자체 서빙 비교를 나중에 이어갈 수 있다.
4. Qwen3에는 **thinking/non-thinking 모드**가 있으므로 고객응대 JSON 출력 학습에서는 `enable_thinking=False`로 우선 통일한다. 이는 품질 우위가 입증된 결론이 아니라 **출력 계약의 일관성을 위한 설계 선택**이다.
5. 약 1.7B 매개변수의 BF16 가중치만 계산하면 약 3.4GB 수준이지만, **실제 학습 메모리는 활성값·최적화 상태·문맥 길이·CUDA 버전에 따라 더 많이 든다.** 24GB GPU에서 먼저 파일럿하고 실측한다.

## 2. 어떤 대안은 제외했나?

- **7~8B 모델부터 시작:** 실험 비용과 메모리 요구가 증가한다. 먼저 작은 모델에서 데이터 포맷·학습/평가 흐름을 익히고 필요할 때 확장한다.
- **Qwen3.5-2B:** 최신 계열로 검토할 수 있으나 모델 카드상 이미지-텍스트 모델이라 이번 **텍스트만의 SFT 첫 실험에는 복잡도**가 추가된다. 필요성이 보이면 재검토한다.
- **상용 API를 SFT 전 기준선으로 대체:** S05의 GPT-4.1-mini는 **다른 기반 모델**이다. 동일 기반 모델 학습 전후 비교의 대조군으로 간주하지 않는다.

## 3. M2에서 고정할 것 (S08/S09 연결)

- 같은 **기반 모델 체크포인트**에서 미학습(Base)과 SFT(+Adapter)를 비교한다.
- 같은 질문·같은 검색 근거 파일·같은 시스템 프롬프트/출력 JSON·같은 디코딩 설정·같은 채점 기준을 사용한다.
- Dev 6건은 **개발용 지표**에 한정하고 Holdout 6건은 최종 단계까지 평가/설정 선택에 쓰지 않는다. 단 6건으로 일반화를 주장하지 않는다.
- Gold ID는 **후행 채점**에만 쓰며 RAG 검색의 입력/랭킹 또는 생성 모델의 사용자 프롬프트에 넣지 않는다.
- S07 파일럿 26건은 6개 의미 그룹에 불과하고 `training_ready=0`이다. **학습 허가/실제 검색 근거/평가 포맷이 확정되기 전 사용하지 않는다.**
