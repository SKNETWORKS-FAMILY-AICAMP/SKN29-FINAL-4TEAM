# 1주차 진행 기록 추가 — 실습 04 (지표 직접 계산)

- **진행 단계:** v3 6일차 — 독립적인 작은 검색 평가기 설계 및 테스트
- **왜 필요한가:** 검색 정확도 숫자를 스스로 계산·설명하고, 검색 실패를 분모에서 누락하는 문제를 방지하기 위함
- **입력:** `data/gold/mini10_gold_step02.json` + `experiments/step03/embedding_comparison.json`
- **코드:** `scripts/evaluate_mini.py` (검색기의 저장된 채점 결과는 재사용하지 않고 순위와 원본 정답지로 재계산)
- **새 테스트:** `tests/test_mini_evaluation.py` (1위·3위·없음·대체 정답·중복·누락·예외·Gold 불일치·저장 점수 재계산)
- **실행 결과:** 사용자 PC 실행 후 입력할 것. 4/10·6/10·6/10은 **기존 실습 결과**이지 새 실행 증거가 아님.
- **배운 점:** Hit@K는 정답이 상위 K개에 있는지, MRR@K는 첫 정답의 순위를 고려. 양성 질문에서 검색 실패는 0점으로 처리.
- **데이터 한계:** 설명서의 세 구간을 분리한 8문단·상관된 10문항으로, 공식 독립 성능평가 아님.
- **남은 작업:** 실제 결과 JSON으로 재계산 실행 → 출력 검산 → 7일차 결정 기록과 1주차 회고.
